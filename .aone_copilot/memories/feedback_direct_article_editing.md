写博客、论文解读、survey 或其他长文 HTML 时，不要默认先创建临时 Python 脚本来写入文章；优先直接编辑目标 HTML 文件，必要时分段读取、分段替换。

Why: 用户指出每次先写 Python 文件再写文章是多余流程，增加了临时文件、状态复杂度和审查负担；这不是 memory 或 skill 的硬性要求，而是助手执行习惯过度。

How to apply: 只有在需要批量机械转换、结构化抽取、自动生成大量重复片段，或直接编辑会明显更不安全时，才使用临时脚本；使用后必须清理。一般写作任务直接操作 `src/pages/*.html`。
