第一章
先认识几种编程 Agent

如果你刚开始接触编程 Agent，先不用急着比较模型分数、安装一堆插件，或者研究复杂配置。第一步是选一个能让你理解工作方式的入口：给它一个目标，观察它如何读取项目、提出修改，并在你检查后继续。

本文以 Codex 作为主要讲解示例，但这只是为了让后续章节有一条具体、可跟随的操作线，并不意味着 Codex 对所有人都最好。Claude Code 和 Pi 也各有自己的产品形态与设计取向。选择时，先想清楚自己更看重桌面交互、终端工作流，还是可定制性。

Codex：本文采用的入门示例

OpenAI 当前的 Codex 学习文档将 Codex 作为能够从任务目标出发、收集上下文并采取行动的产品来介绍；文档也提供 Codex 首页界面的示意。本文选择 Codex，是因为教程后续会围绕 Codex 与 CC Switch 的配置衔接展开，而不是要证明它在所有场景中胜过其他工具。#OpenAI-Codex-Learn#

需要注意，Codex 有不同的使用入口与功能形态，具体可用能力、登录方式和平台支持可能随产品更新而变化。开始操作前，应以官方文档和你当前安装版本显示的信息为准。不要把某一版桌面应用的界面或某一种账户条件，当成所有 Codex 入口永久不变的规则。#OpenAI-Codex-Learn#

Claude Code 与 Pi：两种不同取向

Anthropic 将 Claude Code 描述为编程 Agent：它可以读取代码库、编辑文件、运行命令，并与开发工具集成；官方文档列出终端、IDE、桌面应用和浏览器等使用入口。因此，它既可以融入终端工作流，也提供图形化入口。#Anthropic-Claude-Code-Overview#

Pi 的官方介绍强调可定制的 Agent Harness。对愿意自行组合和调整工作环境的使用者来说，这是值得了解的另一种取向；但如果你想尽量少做配置、先熟悉 Agent 的基本交互，Pi 未必是最省力的第一站。#Pi-Official-Site#

工具官方资料呈现的特点可以优先考虑的情况
Codex本文后续配置与讲解所采用的具体示例；官方 Learn 页面提供产品介绍与快速开始入口。希望跟随本文后续章节学习 Codex 配置与相关工作流。
Claude Code官方说明其可读取代码库、编辑文件、运行命令，并提供终端、IDE、桌面与浏览器入口。想在 Anthropic 产品体系内使用编程 Agent，或偏好终端/IDE 工作流。
Pi官方项目强调可定制的 Agent Harness。愿意了解并自行定制 Agent 工作环境的使用者。

这张表只对照官方资料直接呈现的产品定位，不是功能完整度、模型质量或性价比排名。具体账号要求、可用地区、价格和功能权限会变化；在作出实际选择前，请查看对应官方页面。尤其要区分“使用某个产品的订阅/账号”和“调用模型 API”：二者是否通用，不能想当然，后续配置章节会单独说明。
