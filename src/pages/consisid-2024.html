Part 1
引言：当身份保持撞上 DiT 时代
身份保持文生视频（Identity-Preserving Text-to-Video，IPT2V）要解决的问题是：给定一张参考人脸图像和一段文本提示，生成一段既听从文本指令、又与参考人脸身份一致的高保真人像视频 #Yuan et al., 2024#。这是数字人内容生产里最直接的落地形态——一张自拍加一句"在巴黎铁塔下回眸微笑"，就应该得到一段"还是你、但场景动作全换"的视频。 到 2024 年，这个任务在图像侧已经打完了上半场：IP-Adapter（2023.08）用 CLIP 特征加解耦 cross-attention 开创 tuning-free 范式，PhotoMaker（2023.12）把身份特征堆叠进文本 token #Li et al., 2023#，InstantID（2024.01）用 ArcFace 特征替换 CLIP，PuLID（2024.04）做对比 ID 对齐，Imagine Yourself（2024.09）走向工业规模 #Yuan et al., 2024#。但视频侧是完全另一番景象：骨干架构正随 Sora（2024.02）、CogVideoX（2024.08）从 U-Net 全面转向 DiT #Yang et al., 2024#，而视频 IPT2V 当时只有两个选项——Meta 的 MovieGen（闭源，30B DiT）#Polyak et al., 2024# 和开源的 ID-Animator；后者基于 U-Net、方法照搬图像模型，只能生成"类 talking head"的短视频，身份保持还差 #Yuan et al., 2024# #He et al., 2024#。换句话说，图像侧的 tuning-free 身份注入配方，没有一个被验证过能搬到 DiT 视频模型上。 ConsisID（PKU-YuanGroup，CVPR 2025 Highlight）补上的正是这个空位：它是第一个开源、免微调（tuning-free）、基于 DiT 架构的身份保持文生视频模型 #Yuan et al., 2024#。它的核心武器不是又叠一个模块，而是换了一整套设计语言——频率分解。
本文一句话贡献：把参考人脸的身份信号按空间频率拆成两路——低频全局特征（脸型轮廓、五官比例）经 GFE 拼接进噪声潜变量浅层，高频内禀特征（眼唇纹理等身份标识）经 ArcFace+CLIP 双塔以 cross-attention 注入每个注意力块——用两处"对症下药"的注入位置补上 DiT 相对 U-Net 的两个先天频率缺陷，再配一套粗到细训练配方，把 CogVideoX-5B 改造成 IPT2V 模型，代价仅 +0.5B 参数。
图 1：ConsisID 能力总览。上：参考人脸按频率分解为低频全局特征与高频内禀特征，分别经 GFE（浅层拼接）与 LFE（注意力块内 cross-attention）注入 DiT；下：生成的身份保持视频可被文本灵活控制在不同场景、动作与装饰中（来源：Yuan et al., 2024, Fig.1）。
Part 2
问题剖析：为什么 U-Net 的注入套路在 DiT 上会失灵
要理解频率分解的必要性，得先看论文问的那个别人没问的问题。现有 DiT 控制方法（Tora、PuLID、Camera_DiT、MovieGen 等）基本是把 U-Net 时代的注入套路——ControlNet、T2I-Adapter、Textual Inversion——直接搬过来用，"没有一项研究检验过这类做法为什么在 DiT 中有效"（no study has yet examined why this approach works with DiT）#Yuan et al., 2024#。ConsisID 的回答是：U-Net 和 DiT 在频率域上各有所长，身份信号不按频率选位置注入，就会撞墙。 论文从扩散模型与 ViT 文献中提炼出两条 Finding，作为全部设计的公理（附录"Support for Key Findings"给出逐条出处，包括 FreeU 关于 U-Net 低频偏置的分析 #Si et al., 2024# 与 U-ViT 关于 ViT 骨干在扩散模型中表现的研究 #Bao et al., 2023#）#Yuan et al., 2024#：

Finding 1：DiT 缺低频补给线

浅层（低级、低频）特征对扩散模型的像素级预测至关重要，能让训练更容易收敛。U-Net 靠长跳连（long skip connections）把浅层特征聚合到解码器——DiT 没有这个机制。

Finding 2：DiT 缺高频感知力

Transformer 对高频信息的感知有限，而高频恰恰是保持面部特征的关键。U-Net 的 encoder-decoder 结构天然拥有多尺度特征（高频丰富）——DiT 缺乏可比结构。
用素描来类比最直观：画一张脸，先用长线条勾出脸型轮廓、五官比例与位置——这是低频（缓慢变化的大结构，论文称之为 profile、proportions、facial shape）；再用短促细密的笔触刻画眼角纹理、唇纹、皮肤标识——这是高频（空间局部化、快速变化的信号，论文称之为 eye and lip textures、intrinsic identification，即不受姿态、年龄、化妆影响的身份标识）#Yuan et al., 2024#。 U-Net 是天生带频率补给线的架构：长跳连不断把浅层低频送往解码器（利于逐像素预测、易收敛），多尺度金字塔天然富集高频。DiT 把这两条补给线全拆了：低频断供导致训练难收敛，高频感知弱导致面部细节糊掉。所以 U-Net 时代的身份注入配方照搬到 DiT 上，会同时撞上"收敛难 + 细节弱"两堵墙——这不是工程调参能绕过的，是架构级的频率缺陷。 结论也就顺理成章：身份控制信号必须先按频率分家，再各自注入 DiT 最"缺"的位置。这就是 ConsisID 全部设计的出发点。
Part 3
模型结构：GFE/LFE 双路，把身份按频率拆开注入

3.1 总览：一图看懂数据流

ConsisID 架在 CogVideoX-5B（DiT 架构）之上 #Yang et al., 2024#。参考人脸图像同时喂进两条路：低频路（Global Facial Extractor，GFE）把"参考图 + 面部关键点 RGB 图"经 VAE 编码后与噪声潜变量在浅层拼接；高频路（Local Facial Extractor，LFE）用 ArcFace 与 CLIP 双塔提取特征、Q-Former 融合，再以 cross-attention 注入每个注意力块内部 #Yuan et al., 2024#。

3.2 低频路 GFE：关键点图是一条"只通结构、不通外观"的旁路

GFE 对应 Finding 1。最直接的做法是把参考人脸与噪声输入潜变量直接拼接（SVD 式参考帧拼接），但参考人脸同时含有高频细节与低频信息——由 Finding 2，高频过早进入 Transformer 既低效又阻碍低频处理；而且直接喂参考脸还会引入光照、阴影等无关噪声 #Yuan et al., 2024#。 论文的解法很妙：先提取面部关键点，把关键点转成 RGB 图像，再与参考图拼接，整体经变分自编码器 \(\psi_\theta(\cdot)\) 编码后与噪声潜变量拼接 #Yuan et al., 2024#。为什么这能滤掉光照/阴影？关键点 RGB 图只编码稀疏的几何布局（眼、鼻、耳、轮廓的位置），不携带任何像素强度信息；光照与阴影属于光度外观属性，只存在于参考图的像素值里，无法经由纯几何通道传导。因此关键点图把模型注意力锚定在面部结构上，"聚焦低频信号，同时把无关特征的影响降到最低" #Yuan et al., 2024#。 低频路的目标函数（在标准扩散损失上追加 \(\psi_\theta(f)\) 条件）： $$ \mathcal{L}_{b}=\mathbb{E}_{x_0,\, t,\, y,\, f,\, \epsilon}\Bigl[\bigl\|\epsilon-\epsilon_\theta\bigl(x_0,\, t,\, \tau_\theta(y),\, \psi_\theta(f)\bigr)\bigr\|_2^2\Bigr] $$ 其中 \(\tau_\theta(\cdot)\) 是文本编码器，\(f\) 是参考图（论文注"此处为简洁忽略关键点"）#Yuan et al., 2024#。这条路的分量有多重？消融显示：去掉 GFE 后模型根本无法收敛，FaceSim-Arc/Cur 只有 0.05/0.05、FID 269.88（完整模型为 0.73/0.75）——低频浅层信号是整个训练能跑起来的前提 #Yuan et al., 2024#。

3.3 高频路 LFE：法医与作家的双塔合奏

LFE 对应 Finding 2。只用 GFE 不够——全局面部特征缺乏高频信息，而"认出是同一个人"靠的恰恰是高频身份标识 #Yuan et al., 2024#。LFE 的设计围绕一个两难展开：
  • 纯 ArcFace 塔：人脸识别骨干提取的特征对表情、姿态、形状等非身份属性不变（年龄和化妆也不改变一个人的核心身份），身份一致性强；但它缺乏编辑所需的语义特征——说不出"这个人正在做什么"，没法按 prompt 改年龄改妆容。
  • 纯 CLIP 塔：语义丰富、可编辑；但 CLIP 没在人脸数据上专门训练过，提取的特征里混着大量与脸无关的信息，会损害身份保真 #Yuan et al., 2024#。
打个比方：ArcFace 是法医——只认人、不管场景，同一人微笑、侧脸、化浓妆的照片它都认得，但描述不了情境；CLIP 是作家——懂语义、会编剧，但没受过人脸专门训练，叙述里净是杂质。LFE 让两塔并行，再用 Q-Former 融合成"既能锁定身份、又能被编辑"的内禀身份特征 \(F\)；对 CLIP 特征施加 Dropout 与 DropToken，把作家叙述里的杂质抖掉，维持 Q-Former 输出中细粒度身份特征的主导地位 #Yuan et al., 2024#。 ArcFace 塔有个关键细节：取骨干的倒数第二层（penultimate layer）而非输出层，因为它"保留了更多与身份相关的空间信息"（沿用 UniPortrait 的做法）#Ge et al., 2024# #Deng et al., 2019#。另外还把识别骨干的浅层多尺度特征（经插值）与 CLIP 特征拼接，补充空间细节 #Yuan et al., 2024#。 融合后的特征 \(F\) 如何注入 DiT？答案是 cross-attention 残差，而且注入点相当讲究——每个注意力块内部，Attention 与 FFN 模块之间 #Yuan et al., 2024#： $$ Z_i^{\prime} = Z_i + \text{Attention}(Q_i^v,\, K_i^f,\, V_i^f) $$ $$ Q^{v} = Z_i W^{q}_i,\quad K^{f} = F W^{k}_i,\quad V^{f} = F W^{v}_i $$ 其中 \(Z_i\) 是第 \(i\) 个注意力块产生的视觉 token，\(F\) 是内禀身份特征，\(W^q\)、\(W^k\)、\(W^v\) 是可训练投影参数 #Yuan et al., 2024#。注意这个结构的巧妙之处：Query 来自视觉 token、Key/Value 来自身份特征——视觉 token 主动查询身份信息，与文本 cross-attention 同构，因此能与文本条件共存不冲突；残差形式 \(Z_i + \text{Attention}(\cdot)\) 保证注入是"增强"而非"替换"。 叠加高频路后的目标函数： $$ \mathcal{L}_{c}=\mathbb{E}_{x_0,\, t,\, y,\, f,\, \epsilon}\Bigl[\bigl\|\epsilon-\epsilon_\theta\bigl(x_0,\, t,\, \tau_\theta(y),\, \psi_\theta(f),\, \varphi_\theta(f)\bigr)\bigr\|_2^2\Bigr] $$ 其中 \(\varphi_\theta(\cdot)\) 是局部面部提取器（LFE）#Yuan et al., 2024#。

3.4 注入位置本身就是贡献：a–g 七方案消融

ConsisID 最有说服力的部分，是它没有把注入位置当成工程巧合，而是做了系统的机制验证——七种注入方案的消融 #Yuan et al., 2024#：

  • 方案 a（仅高频）撞上 Finding 1 的墙：低频断供，训练难度大增，模型无法收敛，FaceSim 崩到 0.05。
  • 方案 b（仅低频）撞上 Finding 2 的墙：FaceSim 0.66 看似不差、FID 104.34 甚至全场最低，但生成的人脸只是在"复制参考图"——难以通过 prompt 控制表情、动作等特征。FID 最低恰是复制的副产品，这里已经埋下"FID 不可尽信"的伏笔。
  • 方案 e 证明"注入到块内"不是随便选的：同样在注意力块附近，从输出端注入只是特征堆叠（"merely concatenates features without directing focus"），0.62 vs 0.73；只有块内注入能让注意力权重直接参与身份 token 的选择。
  • 方案 f/g 直接证明注入位置错了连训练都完不成：往注意力块输入端或之前注入高频，会破坏 DiT 本意的频域分布，梯度爆炸 #Yuan et al., 2024#。

3.5 与 ReferenceNet / Adapter 路线的本质差异

把 ConsisID 放回身份保持方法的坐标系里，它和几条主流路线的差异就清楚了：

PhotoMakerCLIP 身份特征堆叠拼接到文本 token 通道U-Net图像

三个关键差异值得强调：
  • 没有 ReferenceNet。ReferenceNet 路线（如 AnimateDiff 时代的可控生成）要用一个与主干同量级的参考网络逐空间位置提取密集特征，代价沉重。ConsisID 用轻量的"识别编码器 + 语义编码器"双塔换掉了重型参考网络，整个身份通路只增加 0.5B 参数（5.7B vs 基座 5.2B）#Yuan et al., 2024#。代价是身份信号不再是逐位置对齐的密集特征，必须靠频率域分析决定注入位置来补偿——这正是 Finding 1/2 的用武之地。
  • 与 IP-Adapter 同构但不同命。注入算子上 ConsisID 的 cross-attention 与 IP-Adapter 的解耦 cross-attention 同构（Q 来自视觉、K/V 来自身份特征）#Ye et al., 2023#，但 IP-Adapter 是单一 CLIP 特征、U-Net 单一位置；ConsisID 是双塔特征、按频率分家的两个位置，并用两条 Finding 论证了为什么 U-Net 时代的单点注入不能照搬到 DiT #Yuan et al., 2024#。
  • 与 InstantID 同识 ArcFace 但用法不同。两者都看中了 ArcFace 的身份判别力 #Wang et al., 2024# #Deng et al., 2019#，但 InstantID 是图像域单塔 + 姿态网络；ConsisID 认为 ArcFace 单塔"缺乏编辑所需语义"，补了 CLIP 塔与 Q-Former，并把 ArcFace 特征显式定位为"高频"成分、只注入注意力块内 #Yuan et al., 2024#。想深入理解 ArcFace 为什么能提供这种"法医级"身份特征，可以读本站的 ArcFace 深度解读。
Part 4
Training：一致性训练配方与 130K 数据管线
架构之外，ConsisID 的另一半贡献是一套一致性训练配方（Consistency Training Recipe）：粗到细训练（CFT）+ 动态掩码损失（DML）+ 动态换脸损失（DCL）#Yuan et al., 2024#。

4.1 训练信号与损失链 L_a → L_f

训练信号的构造很关键：从训练视频中随机选一帧，用 ArcFace 式 Crop & Align 抽取人脸区域作为参考图——也就是说，训练时参考图与目标视频同源 #Yuan et al., 2024#。文本与参考图一起作为控制信号。 先把损失的起点摆出来——标准的文生视频扩散噪声预测损失（把 \(x_0\) 换成 \(\mathcal{E}(x_0)\) 即得 ConsisID 采用的 latent diffusion 形式）： $$ \mathcal{L}_{a}=\mathbb{E}_{x_0,\, t,\, y,\, \epsilon}\Bigl[\bigl\|\epsilon-\epsilon_\theta\bigl(x_0,\, t,\, \tau_\theta(y)\bigr)\bigr\|_2^2\Bigr] $$ 其中 \(\epsilon \sim \mathcal{N}(0,1)\) 是噪声，\(\tau_\theta(\cdot)\) 是文本编码器 #Yuan et al., 2024#。论文的方法叙事就是这条损失的六步演进，每一步追加一个身份相关组件：\(\mathcal{L}_a\)（无身份条件）→ \(\mathcal{L}_b\)（+低频 \(\psi_\theta(f)\)，Part 3）→ \(\mathcal{L}_c\)（+高频 \(\varphi_\theta(f)\)，Part 3）→ \(\mathcal{L}_d\)（人脸掩码约束）→ \(\mathcal{L}_e\)（动态切换）→ \(\mathcal{L}_f\)（动态换脸+噪声）。剩下的三步演进全部针对"怎么监督"： 第一步，人脸掩码约束。对整幅场景算损失会混入冗余背景噪声，于是从视频提取人脸掩码，经三线性插值映射到潜变量空间（视频潜变量是 (T,H,W) 体素，三线性插值正好把逐帧 2D 掩码对齐到时空下采样后的潜变量网格），再逐元素约束损失 #Yuan et al., 2024#： $$ \mathcal{L}_{d}=M \odot \mathcal{L}_{c} $$ 第二步，动态掩码损失（DML）。如果所有训练步都用 \(\mathcal{L}_d\) 监督，背景永远不受监督，推理时模型就生成不出自然背景 #Yuan et al., 2024#。解法是概率化切换： $$ \mathcal{L}_{e} = \begin{cases} \mathcal{L}_{d}, & \text{if } p \gt \alpha \\ \mathcal{L}_{c}, & \text{if } p \leq \alpha \end{cases} $$ 以概率 \(\alpha\) 决定本步用掩码约束还是全场景损失，\(\alpha=0.5\) #Yuan et al., 2024#。本质上是把"前景监督"与"全场景监督"做成数据层面的随机正则，模拟推理时"既要好脸也要好背景"的混合需求。 第三步，动态换脸损失（DCL）。只用 \(\mathcal{L}_e\) 训练后，模型对训练数据之外的人脸表现差——根因是过拟合出了 "copy-paste 捷径"：模型只用训练帧里出现过的脸训练，学的是"复制参考图"而不是"迁移身份" #Yuan et al., 2024#。解法： $$ \mathcal{L}_f = \begin{cases} \mathcal{L}_e \ \text{where} \ x_0 \cdot \zeta, & \text{if } p \gt \beta \\ \mathcal{L}_e \ \text{where} \ x_c \cdot \zeta, & \text{if } p \leq \beta \end{cases} $$ 以概率 \(\beta\) 把参考图换成训练帧之外的人脸（cross-face，\(x_c\)），并对参考图统一施加轻微高斯噪声 \(\zeta\)，\(\beta=0.5\) #Yuan et al., 2024#。噪声打破参考图与生成目标之间像素级的确定性对应，cross-face 直接构造"参考图不在训练分布内"的样本，双管齐下逼模型走"特征级身份迁移"而非"图像级复制"。
一个通用技巧值得带走：DML 和 DCL 都是"概率化损失切换"——把两种互相冲突的监督信号按 0.5 概率混用，而不是设计复杂的加权。这比调损失权重更稳，也更接近数据增强的思想。

4.2 粗到细训练（CFT）：先学骨架，再抠细节

CFT 是"分层策略：模型先全局学信息，再局部精修" #Yuan et al., 2024#。粗粒度阶段（对应 Finding 1）只用 GFE，模型优先学低频特征——面部轮廓与比例，快速从参考图获取身份、保证序列内一致性；细粒度阶段（对应 Finding 2）加入 LFE，焦点转向高频细节——眼唇纹理，提升表情保真与整脸相似度。 为什么必须分阶段？消融给出了机制层面的答案：去掉 CFT 后"**GFE 与 LFE 表现出竞争行为**，模型难以准确区分该优先处理高频还是低频信息，收敛到次优点"——FaceSim-Arc 从 0.73 掉到 0.54 #Yuan et al., 2024#。两个提取器在同一阶段互相抢梯度方向，是"多条件注入训练不稳"的一个典型样本。

4.3 数据管线：130K 高质量人本视频的四级漏斗

现有人脸数据集（VoxCeleb、CelebV-Text 等）以人脸特写为主、背景被裁掉，不适合"日常生活场景"的 IPT2V，所以作者自建了 in-house 数据集 #Yuan et al., 2024#。管线分四级：
图 5：ConsisID 数据管线。从左到右四级：原始视频 → 场景切分与美学/运动过滤 → YOLO 多视角人脸过滤与关键点检测 → IoU 前后向传播的同一性验证 → SAM2 分割 + Qwen2-VL-72B 标注，最终产出 130K 高质量 clip（来源：Yuan et al., 2024, Fig.data）。
  • 检索：用 "human / woman / man" 关键词从互联网检索视频，剔除低播放、低点赞。
  • 粗过滤：PySceneDetect 场景切分 + 美学分数 + 运动分数过滤，得到 130K 高质量 clip（管线沿用同组 ChronoMagic-Bench 的做法）。
  • 多视角人脸过滤：YOLO-Box 逐帧抽取 face / head / person 三类 bbox，三类齐备才保留；YOLO-Pose 检测关键点（左右眼、左右耳、鼻）过滤关键点密度低的片段；"face" bbox 占帧面积比 <6% 的 clip 直接丢弃。
  • 同一性验证 + 分割标注：不依赖 BoT-SORT/ByteTrack 等现成跟踪器（"缺乏鲁棒性"），而是自研轻量跟踪——首帧给每个 face bbox 分配唯一 ID，然后做 IoU 前向传播 + 后向传播双向匹配；再由 SAM2 生成 face/head/person 掩码并用其跟踪信号修正 ID；最后用 Qwen2-VL-72B 做 Time-Aware 视频描述打标 #Yuan et al., 2024#。

Part 5
Inference：tuning-free 推理、步数玄学与轻量性

5.1 推理配置

推理时不需要任何逐身份微调：直接给定参考图与 prompt，用 DPM 采样器 50 步、classifier-free guidance 6.0 生成 49 帧 480×720、8fps 的视频 #Yuan et al., 2024#。8fps 低于人眼流畅感知阈值（约 16fps），论文建议接 RIFE 插帧后处理到 16fps——插帧后仍清晰，说明原始帧足够连贯 #Yuan et al., 2024#。

5.4 零样本能力外溢

只用真实人脸数据训练，ConsisID 仍零样本泛化出了动漫风格的身份保持风格迁移；把 frame 参数设为 1（或取视频首帧），它还能退化成身份保持图像生成模型 #Yuan et al., 2024#。频率分解学到的身份表示显然比训练分布更通用。

6.7 用户研究：103 份问卷的交叉验证

自动指标之外，论文做了相当扎实的用户研究：103 份有效问卷，每份 80 题、观看 40 个视频片段，二选一投票（binary voting），覆盖身份保持、视觉质量、文本相关、运动幅度四个维度。质控规则详细到——视频顺序随机化、提交需滑动验证防机器人、每 IP 限一次、90% 以上答案全选同一选项的问卷作废、完成时间低于 2 分钟的剔除（正常需 2–5 分钟）#Yuan et al., 2024#。
图 6：用户研究结果。ConsisID vs ID-Animator 的二选一投票占比——Identity Preservation 69% vs 31%，Visual Quality 81% vs 19%，Text Relevance 92% vs 8%，Motion Amplitude 79% vs 21%（来源：Yuan et al., 2024, Fig.user study）。
四项全部大幅胜出，其中文本相关性优势最大（92% vs 8%）——这正是"复制粘贴"与"可编辑生成"的用户侧证据。

Part 7
讨论与启发：频率视角给了这个领域一套坐标系

7.1 指标危机：FID 与人类感知负相关

FID 在这个任务上会"指鹿为马"

论文用用户研究交叉验证自动指标后发现：FID 与人类感知呈反向关系——质量更差的 ID-Animator 反而拿到更好的 FID（117.46 vs 151.82），因此作者明确要求"正文中的定量结果应谨慎解读"，FID 仅作参考；CLIPScore 与人类感知的对齐也"仍然有限" #Yuan et al., 2024#。原因不难理解：ConsisID 的 FID 只在人脸区域上计算（InceptionV3 特征空间），而"生成一张和参考图几乎一样的脸"（复制粘贴）在这种分布距离上几乎必然得分——w/o LFE 变体 FID 最低（104.34）正是这个机制的极端体现。本系列此前讨论过的 Face Consistency Benchmark、StyleID、ID-Sim 等评测工作，正是对这一指标危机的后续回应。

7.2 局限

  • 生成规格受限：49 帧 @8fps，需外挂 RIFE 插帧才能到流畅帧率；单次生成约 6 秒。
  • 复现细节缺口：提取器冻结策略、Q-Former 结构细节、CFT 阶段划分、ζ 噪声形式、训练时长等 8 项细节未披露；in-house 数据仅开源子集（CC BY 4.0），完整复现训练需自建数据管线 #Yuan et al., 2024#。
  • 单身份设计：全部实验为单参考人脸，多身份/多主体是后续工作（Concat-ID、Phantom、SkyReels-A2、HunyuanCustom 等）的增量方向。
  • 指标之痛（作者自认）：现有指标无法准确评估 ID 保持能力，未来需要更贴近人类感知的指标——这一痛点后来由同组的 OpenS2V-Nexus 基准接续解决。

7.3 在数字人地图上的位置

ConsisID 的行业意义在于把身份保持从 U-Net 时代（ID-Animator 限于 talking head）带入 DiT 时代：被引已超 160 次，快手 Phantom、昆仑万维 SkyReels-A2、腾讯 HunyuanCustom 等工业工作在讨论 DiT 注入位置时都以它的"低频浅层 + 高频注意力块内"配方为参照系 #Yuan et al., 2024#。它的"DiT 频率二分法"（两条 Finding）也为解释"为什么身份控制信号要分层注入 DiT"提供了通用框架。 放在本站的系列文章里看：ConsisID 代表的是训练时机制路线中的频率分解分支——它讲的是"身份信号怎么注入基座"；而 HunyuanVideo-Avatar 代表的是 MM-DiT 上音频驱动人物动画路线，讲的是"音频怎么驱动已有一致性的角色"（有意思的是，HunyuanVideo-Avatar 并不引用 ConsisID——两者分属音频驱动与 IPT2V 两条文献链，真正引用 ConsisID 的混元系工作是 HunyuanCustom）；想理解 LFE 为什么选 ArcFace 做身份塔，可以回看 ArcFace 深度解读中关于加性角度间隔损失的推导；而它所依附的"视频基模"这一层，则属于本站 数字人系列（五）：扩散基模与整帧数字人路线的讨论范围。

7.4 可操作启发

给做数字人的工程师四点带走的东西：
1. 给 DiT 注入条件前，先问频率——低频信号拼浅层、高频信号进注意力块内（Attention 与 FFN 之间），这个配方有 a–g 消融和傅里叶谱双重背书，可迁移到任意 DiT 条件注入任务；
2. 注入位置错了连训练都完不成——往注意力块输入端注入会梯度爆炸，输出端注入只是无脑拼特征；位置本身就是一个需要消融的关键超参；
3. 反捷径训练用"概率化损失切换"就够了——DML（α=0.5）防背景退化、DCL（β=0.5）+ 噪声 ζ 防 copy-paste，比复杂加权更简单有效；
4. 引用这个领域的 FID 数字前先看人评——FID 与人类感知负相关是论文自己盖章的事实，FaceSim 类指标 + 用户研究才是这个任务的正确量尺。

复习速查

  • 两条 Finding：DiT 无长跳连缺低频（难收敛）；Transformer 高频感知弱（细节糊）。
  • 双路设计：GFE（参考图+关键点 RGB 图 → VAE → 浅层拼接）补低频；LFE（ArcFace 倒数第二层 + CLIP 双塔 → Q-Former → 每个注意力块内 cross-attention）补高频。
  • 损失链：L_a 标准 → L_b +低频 → L_c +高频 → L_d 掩码 → L_e 动态切换（α=0.5）→ L_f 动态换脸+噪声（β=0.5）。
  • 训练配方：CFT 粗到细（先 GFE 后 LFE）+ DML + DCL。
  • 关键数字：FaceSim-Arc 0.58 vs ID-Animator 0.32（主表）；+0.5B 参数、1.8k steps、t=50 峰值；FID 与人类感知反向。
