# 如何做笔记

我之前发现 Agent 可以辅助做笔记，就一股脑把所有事都交给它，但现在发现这样不行。让 Agent 做笔记完全不符合费曼学习法，因为费曼学习法要求把自己学到的东西输出来。如果让 Agent 帮我输入、帮我输出，我自己什么都没做。

所以我现在的想法是，必须把“输出”牢牢握在自己手里，输出才是学习最重要的一环。你可以这样想：你训什么，就能得到什么。我学习的目的是能做出东西来，做东西和输出是一回事。如果把输入和输出都交给 AI，最后我什么都没训练到。

我可以让 AI 帮我输入，这是能替代的部分；也可以让 AI 帮忙整理，因为整理属于输出的后处理，交给程序化、数字化的工具没问题。但“输出”本身必须由我自己来做。
