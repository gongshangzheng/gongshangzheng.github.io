以下保留用户追加口述原文。关于“O(n²)降到O(n)”的说法尚须在结构审阅中明确计算范围；原话不作静默改写。

#+begin_quote
你要讲解一下KV Cache是什么东西。首先我们定义 KVCache 是一个自回归模型推理使用显存换计算量的技术。它可以节省重复计算，但是会增加显存占用。这个定义好像在我们的文章里面，文章开头缺少了。就它的本质是自回归生成的时候，每生成一个新的 Token，模型都要基于之前所有 Token 做注意力计算。如果没有缓存的话，那每一步都要把历史的 Key 和 Value 重新算一遍。所以 KV Cache 就是把已经算过的 KV 存进显存，下一步就可以直接复用，后面就只需要计算新 Token 的 KV。它本质来说就是用额外的显存空间，避免对历史 Token 的重复矩阵运算。但是缺点就是显存占用会随着序列长度线性增长。使用了 KVCache 以后，计算量从 O(n²) 量级降到了 O(n) 量级。这个时间复杂度的计算你也得找个地方插进去。你可以先找到它的那个草稿，然后在草稿里面规划一下它的结构，对它还有 OpenSpecChange，总之就是要更新一下它的结构，结构确定了以后再对正文进行补充
#+end_quote
