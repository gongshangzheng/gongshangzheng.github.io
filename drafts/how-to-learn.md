# Brainstorming — 如何学习

## 核心问题

为什么"学了就忘"是大多数人的默认状态？我们花大量时间输入（读、听、看），却很少真正**习得**。
这篇文章要回答：**怎样才算真正学会一个东西？有哪些可复制的底层习惯能把"学过"变成"学会"？**

立意不是罗列学习技巧，而是建立一个**可自我复用的学习闭环**——让读者带走一套能立刻套用到
任意新领域的最小可行方法。

- **费曼学习法**（Richard Feynman 的方法论）核心四步：
  1. 选定一个概念，假装要教给一个 10 岁孩子
  2. 用最朴素的语言写下来 / 讲出来
  3. 卡壳的地方 = 你没真懂的地方 → 回原始材料补
  4. 简化语言、用类比，直到能流畅讲清楚
- **认知科学支撑**（写作时可作为每条习惯的"为什么 work"）：
  - 主动检索（active recall）：提取本身比重复阅读更强
  - 间隔重复（spaced repetition）：遗忘曲线对抗
  - 交错练习（interleaving）：混合题型比集中练习迁移更好
  - 精细化编码（elaboration）：用自己的话 + 与已有知识连结
  - 双重编码（dual coding）：文字 + 图像
- **可对标站内**：`categories/课程/认知科学` 下的笔记（若有关联，做交叉链接）

## 预期大纲

- **Part 1 · 学习的假象**：输入 ≠ 习得。被动阅读的流畅感是一种"理解的错觉"（illusion of competence）。
  用一个反直觉实验切入（如"读完后合上书你能复述多少"）。
- **Part 2 · 费曼学习法：以教代学**：四步详解 + 为什么 work（输出倒逼理解、暴露知识缺口、
  精细化编码）。给一个具体可操作的最小流程。
- **Part 3 · 记忆的底层习惯**：从参考视频提炼的 5 个习惯（⚠️ 待补，每条配认知科学解释）。
  初步猜测方向（待视频核实后替换）：
  1. 主动检索 > 重复阅读
  2. 间隔重复对抗遗忘
  3. 用自己的话复述（elaboration）
  4. 睡眠巩固（记忆在睡眠中固化）
  5. 检索-反馈闭环（错题/卡点定位）
- **Part 4 · 把习惯串成闭环**：学新东西的完整循环 = 输入 → 费曼输出 → 检索 → 发现缺口 →
  回补 → 间隔重复。给一张流程示意。
- **Part 5 · 可带走的最小清单**：3 条立刻能做的事（如"每学一节合上书写一段话"、"睡前 5 分钟
  回顾今天学的"、"每周给朋友讲一个新概念"）。

## 关键论点（写作时要立住的）

1. **"学过"≠"学会"**——判断标准是"能否教会别人 / 能否在无提示下提取"。
2. 费曼不是技巧，是**诊断器**——它不让你学会，它告诉你哪里没学会。
3. 记忆不是"记进去"，是"能提取出来"——所以练习的方向是**检索**而非**输入**。
4. 5 个底层习惯不是并列清单，要串成一个闭环（输入→输出→检索→回补→巩固）。
