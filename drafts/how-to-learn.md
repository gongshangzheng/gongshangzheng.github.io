# 如何学习

要想搞懂如何学习，最主要的一个点就是要参考费曼的学习法。那费曼是怎么学习的呢？根据参考视频里的内容，主要是五个点：

1. 把学习当成游戏
天赋其实没那么重要，真正重要的是你能够真的在乎学习，把学习当成一件快乐的事，这样自然而然就会让你喜欢去做。

2. 真正去理解一件事
按照费曼的说法，需要纠正学习目标。学习的目标不是把知识刻板地背进脑子，而是以输出为目标。输入的时候就要想着如何整理好，讲解出来，让 12 岁的孩子也能听懂。

3. 记录自己不知道的东西
这点也很重要。很多人没想明白自己到底要什么，把自己不知道的东西记下来，让脑子去思考这些问题，真正开始渴求答案，得到时记忆会更深刻。

4. 列出终身问题
可能是 3～5 个，或者能力强一点是 10～12 个。就是那些闲下来时你真正会去想的问题。

5. 养成习惯
如果能把这五个问题养成习惯，最后就能很快提升自己，可能几个月就能发现很大提升。

我现在的一个想法是：人很多时候都不想开始做事，觉得自己不够努力无法成事。但实际上当你开始做的时候，可能很快就会发现起效果。比如我最近健身，本来觉得会花费很多精力，但实际上开始做后，仅仅一周时间我就发现腹肌变硬了，背后赘肉变少了，精气神提起来了，身姿挺拔了，做事态度也得到了提升，晚上熬夜也变少了。这些都是很好的提升，有时候真的就是一开始去做它而已。
