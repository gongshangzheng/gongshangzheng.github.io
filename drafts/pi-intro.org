* Pi 编程助手：本地 AI 编程的全新体验

** 什么是 Pi？

Pi 是一个 AI Agent. 特点是极简。

** 安装与配置

Pi 通过 npm 安装：
#+BEGIN_SRC bash
npm install -g @earendil-works/pi-coding-agent
#+END_SRC

配置主要涉及：
1. API Key 设置（支持多种模型）
2. Skill 目录配置
3. 工作目录设置

配置可以参考：
