## Context

现有 3DGrowthNet 笔记嵌在 `drafts/orthodontic-outcome-prediction.org` 的正畸主题草稿中，既有论文机制记录，也有面向正畸任务的个人问题与延伸思考。新草稿从该文件抽取并重组论文相关内容，正畸应用讨论不作为新草稿主线。当前资料入口包括 `raw/_face-future-pdfs/` 中的 PDF/抽取文本；需进一步确认它们与草稿所称 3DGrowthNet 论文的对应关系。`raw/diffage3d/` 记录的是另一篇 DiffAge3D 论文，不能误用作 3DGrowthNet 来源。

## Goals / Non-Goals

**Goals:**
- 新建独立的 `drafts/3dgrowthnet.org`，默认使用 org 格式及草稿 frontmatter。
- 先用高层视图讲清论文整体思路，再按思路逐层解释模块、损失、训练和实验。
- 将用户提出的主线“身份、年龄、性别因素如何分离”作为贯穿问题，但把模型设计目标与论文实验实际证明的结论区分开。
- 明确区分论文可追溯事实、草稿作者的直觉解释、尚待原文核实的信息。

**Non-Goals:**
- 不创建或修改 HTML 博客文章，不发布。
- 不把现有正畸草稿整篇搬迁或删除，也不在本 change 中决定其后续去重方案。
- 不把草稿中的每个主张默认视为已核实论文结论。

## Decisions

1. **采用“总览 → 逐个思路拆解 → 训练流程 → 能力与边界”的叙事。**
   先回答论文想解决什么、输入输出是什么、整体系统如何串联；随后分别解释条件表示、重建表征、条件变换与身份保持、循环一致性、对抗真实性，最后把它们放回一次联合训练迭代中。这样避免读者先遭遇一串损失函数、却不知道各项约束在解决什么。

2. **将预训练与联合训练分开说明，但不把分类器等同于解耦机制。**
   预训练年龄/性别分类器提供属性判别信号；连续年龄嵌入器提供可输入的条件表示。联合训练再通过属性一致性、身份保持、重建/循环和对抗目标共同塑造模型。分类器是否冻结、梯度如何传递及各项损失的精确施加对象，必须按论文原文核对后写入；不能仅由当前草稿推断。

3. **把“解耦”写作优化目标与证据问题，而不是先验事实。**
   说明模型希望改变年龄或性别条件时保留身份信息，但潜空间损失不能自动保证语义完全独立。分别呈现训练假设、机制和实验结果，避免将有限评估夸大为成功解耦的普遍证明。

4. **将应用拆成不同推理路径。**
   连续年龄变换、年龄/性别估计、条件形状生成分别说明输入条件、经过的模块及输出，不将它们混成一种“生长预测”。对 60 名儿童纵向数据等具体验证标注其样本、时间跨度与指标口径。

5. **事实源优先级。**
   论文原文 PDF/可靠抽取文本优先；其次为现有草稿中的整理笔记。若没有确认论文元数据或主张与具体 PDF 的对应关系，应在草稿标记“待核验”，不能从相邻主题文件借用信息。插图以论文原图或现有可靠截图为主，并在草稿中保留来源说明。

## Risks / Trade-offs

- [当前素材中的 3DGrowthNet 论文与 `raw/_face-future-pdfs/` 各 PDF 对应关系尚未确认] → 开始填写详细论文事实前先核对标题、作者及方法；无法对应的数值暂标待核验，不写成定论。
- [现有笔记可能把方法机制、作者结论和个人推断混在一起] → 草稿用明确的小标签区分“论文报告”“直觉解释”“待核验”。
- [损失函数之间关系较多，逐项讲解易造成重复] → 在思路总览提供一张组件/目标职责表，细节章节按训练数据流展开，训练流程节只作串联总结。
- [独立草稿与旧正畸草稿短期重复] → 本 change 保留旧文件作为来源，完成新草稿后再由用户决定是否清理旧笔记。

**核心问题与解法速览（草稿写作要求）**
- **问题是什么？** 从 3D 面部网格建模年龄相关形态变化，并支持连续年龄条件下的个体变换及条件形状生成。具体论文任务、数据定义与既有方法缺口，须核准目标论文身份后从引言/方法回填。
- **作者的解决办法是什么？** 现有笔记将其概括为连续年龄嵌入、年龄/性别条件分类器、CVAE-GAN 与多项一致性/对抗损失组成的条件生成框架；该描述暂作为待核实的规划线索，不能先写成已确认论文事实。
- **核心思想（几句话）**：先让潜变量表示可用于重建的个体面部信息，再通过显式年龄/性别条件控制生成；属性监督要求输出符合条件，身份和循环约束尽量保留个体信息，判别器鼓励网格分布逼真。这是针对当前笔记的解释性假设，需逐项回源校正。
- **具体机制（几句话）**：规划中将跟踪真实网格如何经编码器/解码器重建、如何替换目标属性生成变换网格、哪些损失作用在哪些样本/分支，以及随机潜变量如何用于条件生成。每项机制必须附目标论文具体章节、公式/表格定位；未核实则标注待核验。

## Decisions

- 新建独立草稿 `drafts/3dgrowthnet.org`，不直接将整理结果塞回综合正畸预测草稿。
- 叙事从读者的全局心智模型出发，而不是按论文原章节顺序堆砌模块或公式。
- 将用户关心的身份/年龄/性别解耦贯穿全文，但不预设“预训练分类器已完成解耦”；详细机制以目标论文原文为准。
- 原草稿保留作来源与历史，不在本 change 中删改；新草稿完成后可另行决定去重。
- 当前尚未确认 3DGrowthNet 的准确题名、作者以及对应原文文件；因此详细写入前需先确认素材映射。若现有 PDF/文本不匹配，计划先补充获取论文原文，而不是错误复用 DiffAge3D 素材。

## Risks / Trade-offs

- 论文本体素材映射不清会影响所有公式、训练流程和数值的可信度；先核准身份与文件后再迁移笔记。
- 草稿包含较多方法细节，若不区分“论文事实”和“解释性比喻”，可能让读者误以为优化目标提供严格因果解耦保证；正文用证据标签与边界说明控制。
- 当前草稿面向独立论文梳理，不在本次扩展成完整正畸预测方案，以维持主题聚焦。
