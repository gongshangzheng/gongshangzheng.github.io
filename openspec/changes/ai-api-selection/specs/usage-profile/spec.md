# usage-profile

## Purpose

盘点课题组的真实需求与使用画像，为套餐档位选择和成本模拟提供量化输入，替代拍脑袋估计。

## ADDED Requirements

### Requirement: 需求盘点清单
仓库 SHALL 维护结构化的需求盘点清单（问卷/访谈模板），至少覆盖：使用人数与角色、任务场景构成（文献精读/论文写作/翻译/编码/数据分析/批量摘要等）、各场景使用频率、单次任务规模、月预算量级、可用支付方式、合规要求（发票、数据隐私、是否允许境外服务）。盘点结果 SHALL 落盘为 `reports/requirements.md`。

#### Scenario: 完成需求盘点
- **WHEN** 依据清单完成对课题组的盘点
- **THEN** `reports/requirements.md` 包含上述各维度的结论与数据来源（谁提供的、何时）

### Requirement: 用量画像估算
在具备需求盘点结果时，脚本 SHALL 按"场景频率 × 单次任务 token 规模"估算各场景的月度 token 需求，输出总用量分档（轻/中/重）与敏感度区间（乐观/中性/悲观），并标注每项估算的假设。

#### Scenario: 生成分档估算
- **WHEN** 需求盘点数据齐备并运行估算
- **THEN** 输出各场景月度 token 估算表与三档总量区间，每行附假设说明

### Requirement: 本机数据仅作参考
本机 pi 历史数据（如有）SHALL 只能作为个人使用基线的参考附录，MUST NOT 直接作为课题组采购档位的决策依据。

#### Scenario: 报告引用本机数据
- **WHEN** 报告中引用本机 pi 用量数据
- **THEN** 该数据出现在明确标注"个人参考基线"的附录位置，采购建议正文不引用它作为档位依据
