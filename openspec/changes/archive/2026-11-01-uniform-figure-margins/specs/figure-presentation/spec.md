# Spec: figure-presentation

## Purpose

规定正文配图在交付前如何归一留白，使同一篇文章里各图的视觉重量一致，并约束补齐留白的方式不破坏图片自身的背景与动效。

## ADDED Requirements

### Requirement: 正文配图留白比例统一

被页面引用的静态配图 MUST 在交付前统一到同一档留白：先裁到内容边界，再按图片自身宽度补出固定比例的四边留白。留白比例 MUST 以渲染尺寸为基准（正文图以容器宽度铺满显示）。

#### Scenario: 留白过大的图片被裁到位

- **WHEN** 某张配图的四边留白超过统一档位
- **THEN** 交付前裁到内容边界，并补出与统一档位一致的留白

#### Scenario: 没有留白的图片被补到位

- **WHEN** 某张配图内容顶到边缘、四边没有留白
- **THEN** 交付前补出与统一档位一致的四边留白

#### Scenario: 同一页面内留白一致

- **WHEN** 同一页面展示多张静态配图
- **THEN** 这些图片的留白比例一致，差异不超过 1 个百分点

### Requirement: 补白颜色匹配图片自身背景

补齐留白 MUST 使用该图片自身检测到的背景色，MUST NOT 统一填成白色。带透明通道的图片 MUST 保留透明通道。

#### Scenario: 非白底图片不为白色描边

- **WHEN** 某张配图的背景是浅灰或其他非白色
- **THEN** 补出的留白与该图片背景同色，不出现白色描边

#### Scenario: 透明背景图片保留透明

- **WHEN** 某张配图带透明通道
- **THEN** 归一后仍然带透明通道，补白不引入不透明填充

### Requirement: 动态图与矢量图豁免

动态 WebP 与 SVG MUST NOT 参与留白归一：前者逐帧处理会损失动效，后者本就随尺寸自适应。

#### Scenario: 演示动画不被改写

- **WHEN** 某张配图是多帧 WebP
- **THEN** 归一流程跳过它，帧数与内容保持不变

#### Scenario: 矢量图不被改写

- **WHEN** 某张配图是 SVG
- **THEN** 归一流程跳过它，文件保持原样

### Requirement: 归一结果可校验

归一 MUST 是幂等的（重复执行不再改变文件），且归一后的留白 MUST 不超过既有图片留白门禁的阈值。

#### Scenario: 重复执行不再改动

- **WHEN** 对同一批图片连续执行两次归一
- **THEN** 第二次不产生文件改动

#### Scenario: 归一后通过留白门禁

- **WHEN** 对归一后的图片运行 `scripts/check-figure-whitespace.py`
- **THEN** 全部通过，不再报告可裁留白超限
