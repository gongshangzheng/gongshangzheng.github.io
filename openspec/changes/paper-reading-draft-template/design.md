## Context

See `proposal.md` for motivation. 模板放在 blog-drafts skill 的模板目录，采用 Org-mode，与默认草稿格式保持一致。它作为论文笔记的默认模板，服务于深读型论文笔记；`paper-note.org` 仅用于用户明确要求快速记录/快读时，不作为默认流程。

## Goals / Non-Goals

**Goals:**
- 让六部分结构形成从任务定义、方法机制到实验证据的连贯讲解。
- 让作者用数学符号明确问题，而非只给模糊的自然语言摘要。
- 给出 Org-mode 与博客 MathJax 兼容的公式书写规范。
- 将核实事实写成确定陈述并给出论文定位；模板不鼓励把核查过程、旧笔记来源或未完成状态写进面向读者的正文。

**Non-Goals:**
- 不代替论文原文核查、文章 OpenSpec 审批或 HTML 发布流程。
- 不强制每篇论文都具有相同数量的关键点、损失函数或实验。
- 不将 Org 草稿语法与最终 HTML 的组件语法混为一谈。

## Decisions

1. **新增独立模板，而不是改写 `paper-note.org`。** 深度论文笔记（`paper-reading-deep.org`）是默认流程；快速笔记与深入讲解的目的不同，`paper-note.org` 仅在用户明确要求快读/简记时使用。
2. **采用六个主章节，关键点章节可重复。** 固定宏观叙事顺序；关键点数目按论文实际贡献确定。每个关键点包含问题、机制、数学/结构表达、与其他模块关系及适用边界。
3. **任务部分必须形式化。** 要求定义数据样本、输入输出、条件变量和目标映射；按论文需要写重建、条件变换、条件生成、预测/估计等任务，并区分任务目标与训练代理损失。公式不强求统一为某类模型。
4. **公式正文使用 Org 可识别的 LaTeX 片段。** 行内用 `\\(...\\)`，独立公式用 `\\[...\\]`，公式独立成段；不使用 Markdown 代码围栏包公式，不把公式误当普通反引号代码。MathJax 中的 LaTeX 命令、界定符和符号定义需要检查。模板另提示：Org 标题星号层级、粗体/斜体/行内代码/删除线、代码块、链接、图片与表格语法。避免把 Markdown 语法伪装成 Org 示例。
5. **正文不写调研过程噪音。** 模板提示先完成原文核对，再写面向读者的准确陈述；引用章节/页码用于追溯依据，不用“待原文核实”“旧笔记写道”等占位措辞。
6. **实验按问题组织。** 每项结果写评测设置、指标、对照、数值和结论边界；不同指标不合并成过度概括的单一结论。

## Risks / Trade-offs

- [公式模板过于具体] → 以任务类别示例说明用途，明确按论文实际输入输出改写，不要求每项任务都套用。
- [Org 与 HTML 公式环境混淆] → 明确草稿使用 Org 可解析的 `\\(...\\)` / `\\[...\\]`；发布到 HTML 后按博客 MathJax 规则复核。
- [模板让文章变成填表] → 每节写作提示强调解释逻辑与段落衔接，表格仅在比较/数据密集时使用。

## Migration Plan

新增模板文件即可；现有草稿和模板不迁移、不改写。通过人工检查章节提示和语法示例，并确认 OpenSpec change 校验通过。
