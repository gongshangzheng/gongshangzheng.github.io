# Phase 3 · 中文转写规范

**目标**：把清洗后的原文转成干净、忠实、可读的中文。详细规则见 `references/translation-standards.md`，本文件只列决策点。

## 3.1 转写立场

- **忠实精炼，非逐字硬译**：保留全部事实（人名、日期、数字、地点、罪名、人物关系、操作手法），但用自然中文重述，不照搬英文句式、不继承 OCR 乱码
- **合成而非复制**：book-to-skill 的核心原则——不贴原文长段，转述事实骨架并润色。原书公版时可较完整转写条目式内容（人物描述/履历），但仍需语句通顺
- **不臆造**：原文没有的细节绝不补充；OCR 读不清处宁可标 `[原文不清]` 也不瞎编

## 3.2 人名处理

- 首次出现：`英文原名（中文音译）`，如 `Rufus Minor（鲁弗斯·迈纳）`
- 后续：用英文原名，避免音译不一致
- 别名/绰号：保留原文，如 `alias "Billy The Kid"`，绰号可加引注
- 跨条目引用编号（原书用 `(22)` 指代第 22 号罪犯）：转写时改为 `（见第 22 号）`，保留原编号便于回溯

## 3.3 地名/术语

- 地名用通行译名（纽约、芝加哥、圣路易斯），生僻地名首次给音译 + 原文
- 罪名/犯罪类型用固定译名表（见 `references/entry-format.md` 的罪名译名表）
- 19 世纪用语（如 "sneak thief""confidence man"）按当时语义译，不现代化

## 3.4 量纲与数字

- 身高/体重等：保留原单位（5 feet 5 inches → 5 英尺 5 英寸），首次可括注公制
- 日期：保留原文格式（March 23, 1878 → 1878 年 3 月 23 日）
- 刑期/金额：原数 + 单位，不换算

## 3.5 篇幅控制

- 每篇方法论讲解：≥ 800 字
- 每个目录条目：100-300 字（姓名/别名/描述/履历精炼转写）
- 单篇总量：常规 3000-6000 字，超 6000 考虑拆篇
- 总系列：宁多勿少，但每篇独立可读

## 3.6 引用

- 原书作为唯一来源：正文事实句标 `#Byrnes 1886#`（或对应 cite-key）
- 底部 `.sources` 列一条原书：作者、书名、年代、来源 URL（archive.org 链接）
- 条目内部不再逐条标引用，整篇标注即可

## Gate 条件

进入 Phase 4 前必须满足：

- [ ] 罪名/术语译名表已定（目录类书）
- [ ] 人名处理规则已确认
- [ ] 已读取 `references/translation-standards.md`
- [ ] 每篇的素材区间已从 `sources/structure.md` 划定
- [ ] 已创建 todo 并将 Phase 4 设为下一步
