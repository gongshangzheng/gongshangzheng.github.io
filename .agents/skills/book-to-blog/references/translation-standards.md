# 中文转写规范

> 本文件是 book-to-blog 的转写细节参考。Phase 3 读取。

## 核心立场

**忠实精炼，非逐字硬译。** 保留全部事实（人名、日期、数字、地点、罪名、人物关系、操作手法），用自然中文重述。不照搬英文句式，不继承 OCR 乱码，不臆造。

参考 book-to-skill 的原则：**合成而非复制**——不贴原文长段，转述事实骨架并润色。原书公版时可较完整转写条目式内容，但仍需语句通顺、去噪。

## 人名

- 首次出现：`英文原名（中文音译）`，如 `Rufus Minor（鲁弗斯·迈纳）`
- 后续一律用英文原名，避免音译不一致
- 别名/绰号保留原文：`alias "Rufe Pine"`、绰号 `Billy The Kid`
- 原书用编号交叉引用（如 `(22)`）：转写为 `（见第 22 号）`，保留编号

## 地名

- 通行译名直接用：纽约、芝加哥、波士顿、圣路易斯、新奥尔良
- 生僻地名首次：`原文（音译）`，如 `Petersburg, Va.（弗吉尼亚州彼得斯堡）`
- 州缩写展开：Va. → 弗吉尼亚州，N.Y. → 纽约州，Mass. → 马萨诸塞州

## 数字与量纲

- 身高：`5 feet 5^ inches` → `5 英尺 5.5 英寸`（OCR 的 `^` 是半英寸标记，转写时还原）
- 体重：`160 pounds` → `160 磅`
- 年龄：`Forty-eight years old in 1886` → `1886 年时 48 岁`
- 日期：`March 23, 1878` → `1878 年 3 月 23 日`
- 刑期/金额：原数 + 单位，不换算

## 19 世纪用语

按当时语义译，不现代化：
- `sneak thief` → 顺手牵羊贼 / 潜入贼（视上下文）
- `confidence man` → 骗子 / 诈骗犯（"confidence" 指骗取信任，非"自信"）
- `sawdust man` → 锯末骗子（用锯末冒充钞票的诈骗犯）
- `banana man` 等黑话 → 直译 + 括注含义
- `the bench` / `the bar` → 法官席 / 律师席

## OCR 残留处理

清洗后仍可能有残留，转写时：
- 断词 `manufac-turers` → manufacturers
- long-s 误读：`fathom`/`Hne` 等不通处，对照上下文猜 `line`/`fathom` 等，不通则标 `[原文不清]`
- 乱码人名：与目录其他条目交叉对照；无法确认标 `[原文不清]`
- **绝不臆造**：读不清就标 `[原文不清]`，不猜

## 句式

- 英文长定语从句 → 拆成中文短句
- 被动语态 → 主动："was arrested" → "被逮捕"或"遭逮捕"，频繁时简化为"被捕"
- 保留原书叙事节奏，不添加现代评论（除非用户要求注释）

## 条目式内容

人物描述/履历等条目式内容可较完整转写（公版书），但：
- 每条 100-300 字
- 描述（DESCRIPTION）+ 履历（RECORD）合并成连贯叙述，不分死板的字段块（除非用户要表格）
- 保留所有具体事实：年龄、籍贯、体型、身高体重、发色眼色、特殊标记、同伙、作案手法、被捕记录

## 不做的事

- 不逐字翻译全文（那是机翻，不是转写）
- 不为压缩篇幅删核心人物/罪名/日期
- 不加现代注解（"注：此人..."），除非用户明确要注释
- 不臆造原文没有的细节
- 不在正文里写"原文说""书上写"等元叙述
