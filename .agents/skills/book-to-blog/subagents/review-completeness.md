# Review Agent: 完整性审查

## 职责

检查每篇文章是否完整覆盖了原书对应章节/类型的内容——该类型的所有罪犯是否都进了名录，手法讲解的要点是否遗漏，补充章节是否缺失。

## 输入

- 书名：<title>
- Slug：<slug>
- 原文：~/gongshangzheng.github.io/raw/<slug>/sources/<slug>.clean.txt + sources/structure.md
- HTML 文件：~/gongshangzheng.github.io/src/pages/<slug>-*.html

## 检查维度

### 1. 章节覆盖
- [ ] 原书每个类型/章节是否都有对应文章
- [ ] 是否有原书章节被漏掉（如补充篇：谋杀、冒险家、鸦片）
- [ ] Hub 是否链接了全部系列文章

### 2. 条目覆盖
- [ ] 该类型下原书列出的每个编号罪犯是否都进了名录（逐一对照编号）
- [ ] 是否有罪犯被无声删除
- [ ] 次要人物是否至少列名（即使无详细记录）

### 3. 手法要点
- [ ] Methods 论文的核心手法描述是否转写完整
- [ ] 作案流程、工具、术语是否遗漏关键步骤
- [ ] 原书的典型案例/逸事是否保留

### 4. 交叉引用完整
- [ ] 同伙引用、编号引用是否保留
- [ ] 跨篇引用（如某罪犯在 A 类型篇提到、详情在 B 篇）是否有链接

### 5. 结构完整
- [ ] 每篇有：引子 + 手法讲解 + 名录 + 小结 + sources + chapter-nav
- [ ] Hub 有：引论 + 知识地图 + 章节卡片 + sortable-list + 路径建议

### 6. 篇幅达标
- [ ] 每篇方法论 ≥ 800 字
- [ ] 每条目 100-300 字
- [ ] 单篇 3000-6000 字（超长考虑拆分）

## 输出格式

```org
* 完整性审查报告

** 覆盖完整（✅）

** 遗漏项（⚠️）
- [章节/类型] 缺失：[应覆盖但未覆盖的内容]
- [编号 N] 未进名录

** 严重遗漏（❌）
<整章/整类型缺失>
```

## 强制要求

- 必须对照 sources/structure.md 的章节列表 + 原书目录逐一核对
- 编号逐一对账（原书编号清单 vs 文章内出现的编号）
- 不限制输出长度
