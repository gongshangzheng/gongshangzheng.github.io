# Review Agent: 保真度审查

## 职责

检查中文转写是否忠实于原书——人物信息、罪名归类、数字、日期、地点、人物关系、作案手法是否被正确转写，是否存在误读、夸大、臆造或 OCR 残留乱码。

## 输入

- 书名：<title>
- Slug：<slug>
- 原文：~/gongshangzheng.github.io/raw/<slug>/sources/<slug>.clean.txt
- HTML 文件：~/gongshangzheng.github.io/src/pages/<slug>-chXX.html（单篇或多篇）

## 检查维度

### 1. 人物信息准确
- [ ] 抽查 5 个人物：姓名、别名、罪名是否与原书一致
- [ ] 体貌描述（身高、体重、发色眼色、特殊标记）数字是否忠于原文
- [ ] OCR 残留乱码是否已清洗（断词、long-s、乱码字符）

### 2. 罪名归类正确
- [ ] 每个条目的犯罪类型标签是否与原书一致（Bank Sneak / Forger 等）
- [ ] 译名是否用 `references/entry-format.md` 的固定译名表
- [ ] 是否有把 A 类型罪犯错归到 B 类型篇

### 3. 数字与日期
- [ ] 抽查 5 个日期（被捕、判刑、释放）与原文核对
- [ ] 刑期、金额、年龄是否准确
- [ ] 身高的英寸半数（OCR 的 `^`）是否还原

### 4. 人物关系
- [ ] 同伙/团伙成员的交叉引用编号是否保留
- [ ] 关系描述（"搭档""师父""对手"）是否有原文依据

### 5. 无臆造
- [ ] 原书未提及的细节是否被添加（现代评论、推测动机等）
- [ ] OCR 读不清处是否标 `[原文不清]` 而非瞎编

### 6. 翻译准确性
- [ ] 19 世纪黑话/术语是否按当时语义译（confidence man = 诈骗犯，非"自信的人"）
- [ ] 人名音译是否合理、是否前后一致

## 输出格式

```org
* 保真度审查报告

** 通过项（✅）
<核实的正确项>

** 疑似错误项（⚠️）
- 原文表述：[原文]
- HTML 表述：[HTML 描述]
- 问题：[具体问题]
- 建议修正：[修正]

** 严重错误项（❌）
<同上格式，最高优先级>
```

## 强制要求

- 必须从 `raw/<slug>/sources/<slug>.clean.txt` 原文核对
- 每个 ⚠️/❌ 给出原文出处（章节/编号/行号）
- 不限制输出长度
