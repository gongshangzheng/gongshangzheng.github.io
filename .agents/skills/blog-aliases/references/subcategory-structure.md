# Subcategory 结构与 sub_id 分配参考

> 本文件按需加载：仅在分配新 sub_id 或规划系列文章时读取。

## 1. 分配前强制检查

```bash
# 查看目标 subcategory 的现有编号分布
grep -l 'subcategory: "图像压缩"' src/pages/*.html | xargs grep -H '^sub_id:' | sort -t: -k3 -n

# 或用 blog-search
~/.venv/bin/python scripts/blog-search.py --subcategory "图像压缩" --format json | jq -r '.[] | "\(.sub_id) \(.title)"' | sort -n
```

## 3. 新谱段开段规则

当需要在同一 subcategory 下新增**不同类型**的内容系列时：

| 步骤 | 操作 | 示例（图像压缩/红外） |
|------|------|---------------------|
| 1 | 选择新谱段入口（1000 的整数倍） | 3000 |
| 2 | Hub 占用入口编号 | 3000 = 红外系列总览 |
| 3 | 正文从入口 +100 开始，步长 10 | 3100, 3110, 3120, 3130 |
| 4 | 精读从入口 +500 开始，步长 10 | 3500, 3510, 3520, 3530, 3540 |
| 5 | 每个谱段预留 1000 个编号 | 3000–3999 |

## 5. 禁止事项速查

- ❌ 步长 100（如 200→300→400 或 3100→3200→3300）
- ❌ 同一谱段内混用内容类型（如正文和精读都在 3100–3200）
- ❌ 子系列 Hub 不用整千入口编号（如 3001 而非 3000）
- ❌ 在同一谱段内跳号（如 3100→3130→3160）
