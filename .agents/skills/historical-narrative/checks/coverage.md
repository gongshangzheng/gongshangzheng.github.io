# 素材覆盖检查

在写 HTML 前必须完成素材覆盖检查。

## 检查模板

```text
素材清单（来自 Agent A 序幕/背景）:
- [x] 具体日期/数字/事件
- [x] 场景描写
- [x] 人物故事

素材清单（来自 Agent B 爆发/开端）:
- [x] 具体日期/数字/事件
- [x] 场景描写
- [x] 关键引语
```

## 强制标准

- 每个 subagent 的核心场景，不少于 2 个，必须写入 HTML。
- 每个 subagent 的具体数字/日期，不少于 3 个，必须写入 HTML。
- 每个 subagent 的关键引语必须写入 HTML，可复用，不可删除。
- 禁止以“精简”为由删减核心素材。
