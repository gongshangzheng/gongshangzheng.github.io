# Phase 3 — HTML 正文写作

## 顺序

严格先写 HTML 正文，再获取图片或生成音乐。

## 输出格式

只写 frontmatter + 裸正文。禁止包含：

- `<html>`
- `<head>`
- `<style>`
- `<nav>`
- `<footer>`
- `<script>`
- `<link>`

`build.js` 会自动包裹页面。

HTML 路径：

```text
~/gongshangzheng.github.io/src/pages/<slug>.html
```

图片路径使用：

```text
media/images/<slug>/<file>
```

## 写作风格

- 讲故事，不写百科。
- 用具体的人、场景、细节开章节。
- 数字要落地，例如“1,300 万人失业”。
- 引用当事人原话或回忆录。
- 不回避争议和矛盾。
- 素材多少，正文尽量写多少，不以“精简”为由删核心场景。

## 参考来源

文末必须添加：

```html
<div class="sources">
  <h3>参考来源</h3>
  <ul>
    <li><a href="https://..." target="_blank">标题 — 来源</a></li>
  </ul>
</div>
```

禁止使用 `<div class="article-footer">` 替代参考来源。

## 章节组件

```html
<div class="ch fade-in">
  <div class="ch-label">第一幕 · ...</div>
  <div class="ch-title">...</div>
  <p>叙事段落...</p>
</div>
```

图片放在 `.ch` 章节段落之间，不单独成孤立区块。

## 叙事文章组件使用指南

历史叙事的核心是**讲故事**。HTML 组件服务于叙事节奏，不能打断叙事流。

### 组件角色表

| 组件 | 在叙事中的角色 | 使用频率 |
|------|--------------|----------|
| `.ch` + `.ch-title` | 每个 Act/幕，文章的主要分节 | 每章一个 |
| `.ch-subtitle` | 幕内场景转换 | 按需 |
| `.quote` | **当事人原话、回忆录、书信引用** | 高频——比裸段落更有现场感 |
| `.photo` | 历史图片、人物照片、地图 | 紧跟相关段落，不要堆在文末 |
| `.info-box` | 历史背景补充（制度说明、地理环境、人物小传） | 补充性质，不打断主线 |
| `.callout` | 关键数字、转折点、一句话摘要 | 少用——只在真正需要提炼时出现 |
| `.table-wrap` | 对比表、参战数据、时间线数据表 | 数据密集时使用 |
| `.timeline` | 时间线可视化 | 适合序幕/背景铺陈，不适合叙事高潮 |
| `.sources` | 文末参考来源 | **必须** |

### 叙事节奏原则

1. **以场景切入，不以概括开头。** 每章开头用一个具体的时间、地点、人物动作或原话拉开序幕，不要用"这一时期的主要事件有..."。
2. **高潮场景用段落展开，不被组件盒子打断。** 战争的关键时刻、决策的紧张瞬间、当事人的原话——这些是叙事的核心，用连续的段落推进，不要插入 callout 或 info-box 打断节奏。
3. **引用原话用 `.quote`。** 当事人的书信、回忆录、演讲原文——用 `<div class="quote">` 包裹，比裸引号更有视觉力量。
4. **背景知识用 `.info-box` 隔离。** 制度说明、地理环境、人物生平——这些是叙事的"休息区"，用 info-box 包裹，让读者知道"这里进入补充模式"，读完再回到主线。
5. **数字和转折用 `.callout` 点睛。** 伤亡数字、转折年份、关键决策——用 callout 提炼，但不要滥用。一篇文章 3-5 个 callout 就够了。
6. **叙事文章不使用以下组件：** `def-box`、`theorem-box`、`admonition`、`example-box`、`review-box`——这些属于课程笔记和论文解读的文章类型，不属于叙事。

### 反面示例

```html
<!-- ❌ 用 info-box 打断叙事高潮 -->
<p>1944年6月6日凌晨，盟军在诺曼底登陆。</p>
<div class="info-box">
  <h3>诺曼底地理位置</h3>
  <p>诺曼底位于法国西北部...</p>
</div>
<p>登陆部队在五个海滩同时展开...</p>

<!-- ✅ 背景知识提前铺好，高潮不被打断 -->
<!-- 在前一章铺垫： -->
<div class="info-box">
  <h3>诺曼底：为何选这里</h3>
  <p>诺曼底位于法国西北部，距英国最近的登陆点，海滩地形适合大规模登陆...</p>
</div>
<!-- 本章直接进入高潮： -->
<p>1944年6月6日凌晨，盟军在诺曼底登陆。登陆部队在五个海滩同时展开...</p>

<!-- ❌ 用 callout 打断人物原话的节奏 -->
<p>纳赛尔站在亚历山大港的广场上，面对数万听众。</p>
<div class="callout"><strong>关键转折：</strong>纳赛尔在演讲中宣布运河国有化。</div>
<p>他宣布苏伊士运河收归国有...</p>

<!-- ✅ 让原话自己说话 -->
<p>纳赛尔站在亚历山大港的广场上，面对数万听众。他宣布苏伊士运河收归国有。</p>
<div class="quote">
  <p>「我们用自己的资金建造了运河...我们的人民为运河付出了生命的代价...运河是属于埃及的。」</p>
  <div class="who">——纳赛尔，1956年7月26日国有化演讲</div>
</div>
```
