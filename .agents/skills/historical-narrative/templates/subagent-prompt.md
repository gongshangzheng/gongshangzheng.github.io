# SubAgent Prompt 模板

```text
任务: 收集 [XX历史事件] 在 [时间段] 的故事素材

你需要:
1. 用 web_search（或 GLM 联网搜索 MCP，参考 web-search skill）获取信息来源
2. 用 web_fetch 抓取详细信息，关键页面至少抓取 3-5 个
3. 用中文整理成至少 1000 字的叙事段落

要求:
- 必须包含具体日期、人物姓名、数字数据
- 用讲故事的口吻，不写百科条目
- 标注每个故事的来源 URL，每个段落至少 2 个独立来源
- 捕捉戏剧性瞬间：关键决策、意外转折、当事人的具体经历
- 不要只给概括，必须展开 2-3 个具体场景/人物故事
- 如果有可配图的历史照片/画作，记录 Wikimedia Commons 文件名并验证存在
- 信息不足时标注“信息源未明确给出”，不得编造
- 不要将素材保存为文件，所有内容直接返回
- 绝不在 ~/Org/roam/ 下创建任何文件
```
