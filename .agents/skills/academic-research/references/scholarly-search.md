# 学术检索与证据记录

## 工具分工

开始检索前读取用户级 `~/.agents/skills/web-search/SKILL.md`，网络路径与引擎可用性以其当前规则为准；不要复制某次测试结论为永久保证。再读取 `~/.agents/skills/scientific-agent-skills/SKILL.md`，从 catalog.tsv 定位最小所需工作流并读取 WORKFLOW.md。具体 API 调用前还须读取其数据库参考文件。

- 主题论文发现：CS/数学/物理预印本使用 arXiv；跨领域补查 OpenAlex。既有 web-search 的 arxiv.py、openalex.py 和项目 arxiv-paper-digest 可承担已有能力，不重复造解析脚本。
- DOI 与出版信息：使用 paper-lookup / citation-management 的 Crossref 路线，核对出版商或会议页面。arXiv 标识不等于已在 Crossref 登记的 DOI。
- 引用与被引：使用 paper-lookup 中 OpenAlex、Semantic Scholar 或 OpenCitations；references 是该论文引用的文献，citations 是引用该论文的文献。记录方向、数据库与查询日期；不同数据库的计数不混加，分页未完成不称完整引用集。
- 开放全文：从官方论文页、arXiv、OpenReview、会议论文集寻找；必要时按 paper-lookup 使用 Unpaywall / CORE。找到下载链接与实际取得完整正文是两种状态。
- Scholar：仅作补充，按 web-search 的 scholar-setup.md 使用现有配置；scholarly 是抓取工具，没有官方 Scholar API。遇验证码或连续限流停止，不自动使用公共免费代理池。
- 系统性或范围综述：读取 literature-review，明确纳排标准、筛选过程及检索截止日期。普通领域导览不要自称完成系统综述；PRISMA 仅在适用时使用真实且可核对的筛选数量。
- 通用网页、课程与最新动态：按 web-search 的 Bing / 官方页面路径；课程另查 YouTube、Bilibili。Exa、Parallel 只在任务需要且依赖、鉴权已核验时使用，不因技能存在就声称服务可用。

这些上游工作流提供检索与核验方法；项目的草稿、OpenSpec 审核、原图优先和禁止学术 AI 生图规则仍然适用。检索工作流不自动授权发布、付费查询或生成额外文章。

## 检索过程

1. 明确问题、领域、语言、起止日期、截止日期和交付范围。用户给定论文先按 ID / DOI / 准确标题定位，不先做无关广搜。
2. 设计关键词、同义词和方法名组合；先找 survey，再找代表作和近期工作。综述按覆盖缺口补互补数据库，不以固定数据库数量或高被引排序保证完整性。
3. 保存实际查询与原始结果，再筛选。按 DOI、arXiv ID 和书目信息去重；预印本、会议版、期刊版建立关联，保留实际阅读版本，不能简单作为三个独立贡献计数。
4. 从核心论文的参考文献向前追溯，从被引列表向后追踪。引用数只能帮助阅读排序，不能单独证明质量或决定纳入；新论文不因引用少被排除。
5. 核对标题、作者、年份、版本、撤稿/更正状态和官方 URL。获取原文后交给项目 read-article 的提取脚本与 collect 流程，搜索摘要或网页片段不能替代原文整理。

## 输出记录

在本次材料目录 raw/<topic>/ 下保存 search-log.md、候选论文账本和原始响应。沿用已有账本时直接增加字段，不另建重复事实存储层。

检索日志记录日期、实际 skill/workflow、工具、数据库/引擎、查询、过滤条件、网络路径、结果数量、分页范围及失败原因。密钥与含凭据代理地址不得入日志。

论文账本记录稳定 ID、标题、作者、首次公开日期、发表年份、版本、官方 URL、发现渠道、纳入/排除理由、论文角色及阅读状态。状态至少区分：发现记录、读摘要、取得全文、完成提取、完成深读；不能混称“已读”。深读的公式、图表位置仍存放在 read-article paper packet。

## 失败与覆盖边界

HTTP 200 不代表返回有效论文：检查错误字段、结果结构、标题/ID 和全文正文是否存在。空结果、验证码、鉴权失败、429、超时与部分分页分别记录；不得推断“没有相关研究”。按服务文档限流，有限重试；网络诊断遵循 web-search，不固定代理端口，不自动恢复已停用的搜狗/DDG。

换数据库或网络路径时保留原失败记录，并说明替代渠道的覆盖差异。OpenAlex 等 API 同样可能有配额、鉴权要求或限流，不写“通常不限流”作为调用保证。密钥只检查是否存在，不输出值。

交付时说明实际查了哪些来源、检索截止日期、哪些原文未取得、哪些引用分页未完成。技能文档存在、工具能启动、实际检索成功与完成深读必须分别表述。
