# Web Scan Subagent

## 任务

对一个学术研究领域进行全面背景调研，建立领域地图。

## 输入

- `研究领域`: <用户提供的主题>

## 调研维度

每个维度至少 2 次独立 web_search（或 GLM 联网搜索 MCP，参考 web-search skill）：

1. **当前最热的子方向**
   - 近 1-2 年的重大突破
   - 目前学界最关注的 open problems
   - 业界 vs 学界的关注差异

2. **Landmark papers**
   - 奠定该领域的开创性工作
   - 被最广泛引用的论文（尝试获取引用数）
   - 为什么这些论文重要

3. **关键作者与机构**
   - 该领域最活跃的研究者（至少列出 5 位）
   - 顶级实验室/团队
   - 近期高产作者

4. **近期趋势**
   - 技术发展脉络（从 XX → YY → ZZ）
   - 社区共识与争议
   - 未来 1-2 年的预期方向

5. **实用资源**
   - 重要的 survey/review 论文
   - 开源代码库和工具
   - 常用 benchmark 和数据集

## 输出格式

```
** 热点子方向
<列出并简述每个子方向>

** Landmark Papers
| 论文 | 年份 | 核心贡献 | 引用数 | 关键作者 |
|------+-----+---------+--------+---------|

** 关键作者与机构
<详述>

** 发展脉络
<时间线描述>

** 实用资源
<列表>
```

## 约束

- 不限制输出长度
- 每个维度至少 2 次独立 web_search（或 GLM 联网搜索 MCP）
- 只做调研，不修改任何文件
