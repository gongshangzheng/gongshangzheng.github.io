# Phase 4a · 术语表 + 领域问题定义 subagent

## 任务

从调研全部素材中提取领域核心术语，构建术语表；精确定义调研领域的核心问题。

## 输入

- 研究领域：<topic>
- Phase 0-1 素材：见 ~/Org/roam/note/<topic>/
- Phase 3 素材：见 ~/Org/roam/note/<topic>/

## 分析维度

### 1. 领域核心术语表

从所有论文素材中提取反复出现的核心术语（10-20 个）。每个术语：
- 一句话定义（面向有 ML 背景但不了解该领域的读者）
- 一个类比或具体例子
- 标注是"领域通用"还是"特定论文自创"
- 首次出现时标注英文原文

### 2. 容易混淆的术语对

列出领域内容易混淆的概念对（3-5 对），给出清晰区分。

### 3. 领域核心问题定义

精确描述该调研领域的核心问题：
- 输入空间是什么？
- 输出空间是什么？
- 约束条件是什么？
- 优化目标是什么？
- 为什么这个问题重要？（应用场景、产业需求）

### 4. 之前方案的局限

对该领域的主要历史方案，说明：
- 方案名称和核心机制
- 具体局限（附数据：在什么条件下效果下降多少）
- 局限的根本原因

### 5. 领域发展的关键转折点

列出 2-3 个领域发展中的关键转折点：
- 什么变了？（新数据、新架构、新理论）
- 为什么变了？
- 变化带来的量化改善

## 输出格式（Markdown）

```markdown
# 术语表

## 核心术语

*Term1* :: 定义。类比：...

*Term2* :: 定义。具体例子：...

## 容易混淆的术语对

**A vs B**：区别说明。

# 领域问题定义

## 核心问题

[数学形式化描述]

## 之前方案的局限

### 方案 A
- 机制：...
- 局限：...（附数据）
- 根本原因：...

## 关键转折点

### 转折点 1：[描述]
- 变化：...
- 量化改善：...
```

## 强制要求

- 术语表至少覆盖 10 个核心术语
- 每个术语必须有类比或例子
- 问题定义必须有数学形式化
- 之前方案局限必须有数据支撑
- 只做调研，不修改任何文件
