# 失败路径处理

## 概述

本文件定义了 course-notes skill 中所有可能的失败场景及对应的处理策略。

## 失败场景与处理

### 1. Phase 2: MATERIALS 失败

**场景**：docling 转换 PDF 超时或失败

**处理**：
1. 检查 PDF 文件大小和页数
2. 如果是大文件（>50 页），逐个处理，不并行执行
3. 如果是纯图片 PDF，先渲染关键页为图片再视觉分析；**当前工作机专属**可用 `~/.venv` + `PyMuPDF` 渲染指定页，再用 `read_file` 读取 PNG 确认页面内容；其他机器需先检查 `pdftoppm` / 视觉 MCP
4. 如果仍然失败，告知用户并建议手动提取关键内容

### 2. Phase 3: WEB REFERENCES 失败

**场景**：网页搜索无结果或参考笔记质量低

**处理**：
1. 扩展搜索关键词，使用 3-5 个互补搜索变体
2. 尝试不同的搜索引擎（web_search → mcp_MiniMax_web_search → ddgs_search.py）
3. 如果仍然无结果，使用教材内容作为主要参考
4. 在笔记中说明参考来源有限

### 3. Phase 4: COMPOSITION 失败

**场景**：HTML 生成失败或 build.js 构建错误

**处理**：
1. 检查 html-blog 规范，修复格式问题
2. 检查 LaTeX 公式语法，修复 MathJax 渲染问题
3. 检查图片路径，确保所有引用的图片文件存在
4. 如果仍然失败，不允许用删减内容掩盖问题；应定位失败的具体 HTML/MathJax/资源路径，必要时把复杂组件替换为等价且可构建的规范组件，但必须保留核心知识点、公式、例题和引用

### 4. Phase 5: REVIEW 失败

**场景**：三路审查发现严重问题

**处理**：

#### 保真度审查失败
- 核心概念错误：退回 Phase 2，重新理解课件内容
- 公式推导错误：直接修复或退回 Phase 2
- 例题解答错误：直接修复

#### 完整性审查失败
- 知识点遗漏：退回 Phase 3，补充缺失内容
- 字数不足：扩展已有章节，增加例题和解释
- 配图不足：补充 mermaid/jsxgraph 图或课件截图

#### HTML 格式审查失败
- 组件规范问题：直接修复 HTML
- MathJax 渲染问题：修复 LaTeX 语法
- build.js 构建失败：修复 HTML 结构，重新构建

### 5. 超时处理

**场景**：整个流程超时或某个阶段耗时过长

**处理**：
1. 设置每个阶段的时间上限
2. 如果某个阶段超时，先收窄本次交付范围或拆分任务，不允许产出低配版内容
3. 如果整体超时，优先完成已确认范围内的核心知识点、公式、例题、引用和构建验证
4. 若仍存在未完成范围，必须暂停并向用户确认后续拆分计划，不得在笔记中留下未完成段落

### 6. 用户中断

**场景**：用户要求中断或修改需求

**处理**：
1. 保存当前进度
2. 记录已完成的部分和未完成的部分
3. 根据用户新需求调整后续计划
4. 如果用户要求重新开始，清理已有产出

## 预防措施

### 1. 阶段性检查
- 每个阶段完成后检查 Gate 条件
- 不满足条件时立即修复，不带入下一阶段

### 2. 资源管理
- 监控磁盘空间，确保有足够空间存储图片和 HTML
- 监控网络连接，确保可以访问外部参考

### 3. 备份机制
- 重要中间产物定期备份
- 如果发生不可恢复的错误，可以从备份恢复

### 4. 用户沟通
- 遇到无法解决的问题时及时告知用户
- 提供多个解决方案供用户选择
- 记录用户的选择和偏好，用于后续优化
