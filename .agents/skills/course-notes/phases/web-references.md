# Phase 3: WEB REFERENCES — 网页参考笔记搜索

**目标**：参考网页搜索到的高质量课程笔记、教材说明和教学页面，用来补充直觉解释、定义、推导路径、例题类型和易错点。

读取：`references/web-reference-policy.md`

## 操作

1. 为每个核心主题设计 2-4 个搜索式，中英文均可，优先包含：课程名、概念名、lecture notes、tutorial、教材关键词、大学名。
2. 使用 `web_search`（或 GLM 联网搜索 MCP，参考 web-search skill）搜索。需要详情时用 `web_fetch` 读取网页文本；网页搜索不足时再考虑浏览器。
3. 至少筛选 2 个外部参考来源；复杂章节建议 3-5 个。
4. 记录每个来源的角色：
   - definition：定义更清楚
   - intuition：直觉解释更好
   - derivation：推导更完整
   - example：例题可借鉴
   - caveat：补充适用条件或易错点
5. 只吸收解释结构和事实，不复制整段文字。和课程材料冲突时，以课程材料为主，并标注差异。

## 网页参考卡格式

```markdown
[W01]
标题：
URL：
来源类型：大学课程 / 开放教材 / 官方文档 / 教师笔记 / 博客 / 问答
主题相关性：core / supporting / peripheral
质量判断：high / medium / low
可借鉴点：定义 / 直觉 / 推导 / 例题 / 易错点
使用方式：将用于哪一节
注意事项：是否有版本差异、符号差异、潜在错误
```

## Gate 条件

进入 Phase 4 前必须满足：

- [ ] 至少执行过网页搜索
- [ ] 至少筛选 2 个可用网页参考来源，或说明为什么找不到合格来源
- [ ] 每个网页来源有 URL 和使用角色
- [ ] 已比较网页来源与本地课程材料的一致性
