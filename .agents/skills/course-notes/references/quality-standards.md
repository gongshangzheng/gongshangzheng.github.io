# Quality Standards — 课程笔记质量门

## 必须避免

- 只写摘要或目录。
- 只堆公式，不解释符号和条件。
- 只写结论，不写推导或直觉。
- 用"作业要求/题目要求/老师要求"作为概念讲解主线，导致读者不知道概念本身为什么成立、是什么、怎么用。
- 声称参考课程材料但没有页码、章节、题号或文件路径。
- 声称参考外部资料但没有 URL。
- 复制网页原文，或把网页内容伪装成课程原文。
- HTML 中残留 Markdown 图片语法、模板占位符或不存在的图片路径。

## 核心检查

| 项目 | 最低标准 |
|------|----------|
| 背景动机 | 每个大节说明为什么需要该概念 |
| 概念定义 | 直觉 + 数学定义 + 符号解释，先从概念本身出发，不以题目要求代替定义 |
| 推导 | 关键公式至少展开一条推导链 |
| 例题 | 每个核心概念后至少配 1 个具体例子；涉及题目时，至少 2 道完整步骤 |
| 图片 | 博客长文至少 3 张本地图或明确说明材料不足 |
| 网页参考 | 至少 2 个合格网页来源或记录失败原因 |
| 复习速查 | 表格或 checklist 汇总公式、条件、题型入口 |
| 来源 | 本地课程材料和网页参考分开列出 |

## 数学与工程内容检查

- 变量第一次出现必须定义。
- 公式适用条件必须写清楚。
- 离散/连续、时域/频域、标量/向量等对象不要混用。
- 算法步骤要能手算或复现。
- 例题答案要回代或解释物理/工程含义。

## HTML 博客检查

- 读取并遵循 html-blog。
- **课件轻量引用**：只有当课件页内容已经被正文完整转述、解释或推导，只需要标注来源、页码、前置知识去哪里补时，才用 `docref` shortcode；它应接近增强版链接，不应占据大块页面空间。每个 `docref` 前后必须说明它引用了什么内容，禁止孤立链接。
- **课件整页展示**：正文依赖该页图、公式、框图、频谱或例题版面，或者正文没有完整复现该页内容、读者需要直接看到页面时，源 PDF 拷贝到 `media/`，用 `docpage`/`docpages` shortcode（可交互渲染、按需加载 PDF.js）。`docpage`/`docpages` 必须按“导读段 → 课件页 → 回扣段”放置，页面前说明读者要看什么知识点、为什么看，页面后把课件内容接回正文概念或下一步推导；禁止孤立插入。导读和回扣正文只讲知识点，严禁写“第 X 页说明/展示/给出……”“详细说明在第 X 页”这类页码叙述；页码只保留在 shortcode 参数或参考来源列表。
- **课件局部/需要裁剪标注**：先将目标 PDF 页导出 PNG 到 `media/images/<slug>/`，再裁剪/标注后用 `<div class="photo"><img>`；**当前工作机专属**可用 `~/.venv` + `PyMuPDF` 导出指定页，其他环境可用 `pdftoppm -png -r 300` 等可用工具。docling 提取的图片质量足够好时也可直接用，但必须视觉检查清晰度。
- **数学/信号函数图**：优先用 `jsxgraph`（首选），functionplot 为旧语法兼容。
- **架构图/流程图/时序图**：优先用 `mermaid`。
- **精确 SVG 图示 / SVG 动画**：当 Mermaid / JSXGraph 无法表达标准工程符号、复杂路径、渐变、遮罩、逐步显隐或动画说明时，读取 `svg-animations` skill，用内联 SVG / SVG 动画实现；必须提供可访问性标签，并兼容 `prefers-reduced-motion`。
- **非课件配图**（实验结果截图、手绘示意图等）：复制到 `media/images/<slug>/`，用 `<div class="photo"><img>` 引用，每张图有 caption。
- **配图优先级**：能用代码绘制的图（函数/信号/流程/架构/SVG 精确图示）不要用静态图替代；代码图可交互、可缩放、矢量清晰，维护成本远低于静态图片。
- 不使用 `<html>/<head>/<body>/<nav>/<footer>/<script>`。
- 执行 `node build.js` 并修正错误。
