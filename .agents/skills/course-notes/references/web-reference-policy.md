# Web Reference Policy — 网页参考笔记规范

课程笔记必须参考网页搜索到的外部笔记或教学资料，但外部资料只能用于补充理解，不能覆盖课程原始材料。

## 推荐来源优先级

1. 大学公开课程页面、lecture notes、教学 PDF。
2. 开放教材和官方文档，例如 OpenStax、MIT OCW、Stanford/CMU/Berkeley 课程页。
3. 教师个人课程笔记。
4. 高质量技术博客或教程。
5. 问答站点只用于定位易错点，不作为主证据。

## 搜索策略

- 中文主题：`概念名 课程笔记`、`概念名 推导`、`概念名 例题`。
- 英文主题：`concept lecture notes`、`concept derivation tutorial`、`site:edu concept notes`。
- 工程课程：加入工具名、算法名、实验关键词。
- 数学课程：加入 theorem、proof、example、intuition。

## 质量筛选

每个网页来源检查：

- 作者或机构是否明确。
- 是否有完整上下文，而非碎片答案。
- 符号定义是否清晰。
- 是否与课程材料一致。
- 是否有发布日期或课程版本。
- 是否存在明显错误、广告诱导或 AI 垃圾内容。

## 使用边界

- 可以借鉴解释路径、例题类型、图示思路和易错点。
- 不要复制网页原文大段文字。
- 不要使用网络图片热链；需要图时本地重绘、从课程材料提取，或明确获得可用资源后复制到本地资产目录。
- 与课程材料冲突时，以课程材料为主；如果网页解释更清楚，可以写“另一种理解方式”。
- 引用网页时写清 URL 和用途。

## 最低要求

普通章节至少 2 个网页参考来源。复杂章节建议 3-5 个。若搜索不到合格来源，必须记录搜索式和失败原因。
