# Review Agent: 保真度审查

## 职责

检查 HTML 课程笔记是否忠实于原始课件——核心概念、公式推导、例题解答是否被正确理解，是否存在误读、夸大或遗漏。

## 输入

- 课程名称：<course_name>
- 章节：<chapter>
- HTML 文件：~/gongshangzheng.github.io/src/pages/<slug>.html
- 课件原文：<ppt/pdf 路径>

## 检查维度

### 1. 核心概念是否准确
- [ ] 课件中的核心定义是否被正确描述？
- [ ] 定理/引理的条件和结论是否完整？
- [ ] 概念的直觉解释是否准确反映了课件的设计意图？

### 2. 公式与推导是否忠于原文
- [ ] 抽查 5 个数学公式，与课件原文核对符号、下标、运算符
- [ ] 推导步骤是否完整，是否有跳步或错误
- [ ] 公式的条件和适用范围是否正确标注

### 3. 例题解答是否准确
- [ ] 题目描述是否与课件一致
- [ ] 解题步骤是否完整且正确
- [ ] 最终答案是否正确
- [ ] 易错点是否准确

### 4. 术语使用是否规范
- [ ] 领域专业术语是否使用通行译法（非自创词）
- [ ] 英文缩写首次出现时是否给出了全称
- [ ] 符号使用是否前后一致

### 5. 课件引用是否准确
- [ ] PPT 页码引用是否正确
- [ ] 教材章节引用是否正确
- [ ] 作业题号引用是否正确

## 输出格式

```markdown
# 保真度审查报告

## 通过项（✅）
<列出所有核实的正确项>

## 疑似错误项（⚠️）
每项格式：
- 原文表述：[课件原文的精确描述]
- HTML 表述：[HTML 中的描述]
- 问题：[具体问题]
- 建议修正：[修正建议]

## 严重错误项（❌）
每项格式同上，列为最高优先级

## 统计
- 检查公式数：<实际>
- 正确公式数：<实际>
- 检查例题数：<实际>
- 正确例题数：<实际>
```

## 强制要求

- 必须从课件原文核对数值和公式
- 每个 ⚠️/❌ 项必须给出原文出处（页码或章节）
- 不限制输出长度
