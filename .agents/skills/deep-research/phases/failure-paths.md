# 失败路径与恢复策略

## 通用规则

- 每个 failure path 有明确的**触发条件**和**恢复策略**
- CRITICAL 级别问题**阻断流水线**，必须立即处理
- 用户可随时中止，保存进度供后续恢复

## 失败场景清单

| # | 场景 | 触发条件 | 恢复策略 |
|---|------|---------|---------|
| F1 | RQ 无法收敛 | Phase 1 / Socratic Layer 1 经多轮仍模糊 | 提供 3 个候选 RQ 或建议先做 lit-review |
| F2 | 文献不足 | bibliography 找到 < 5 个来源 | 扩大搜索策略、更换关键词、尝试其他数据库 |
| F3 | 方法不匹配 | RQ 类型与方法能力错位 | 回到 Phase 1，建议 3 种替代方法 |
| F4 | Devil's Advocate CRITICAL | 发现致命逻辑缺陷 | **STOP**，解释问题，要求修正 |
| F5 | 伦理 BLOCKED | 严重伦理问题 | **STOP**，列出问题和补救路径 |
| F6 | Socratic 不收敛 | > 10 轮对话未收敛 | 建议切换到 full 模式 |
| F7 | 用户中途放弃 | 用户明确表示不想继续 | 保存进度，提供重入路径 |
| F8 | 仅中文文献 | 英文搜索返回空 | 切换到中文学术数据库 |
| F9 | 编辑 REJECT | Phase 5 编辑决定为 REJECT | 分析原因，建议重大修改或终止 |
| F10 | 修订循环耗尽 | 2 轮修订后仍有未解决问题 | 记入 Acknowledged Limitations |
| F11 | 系统性综述协议不完整 | PICOS 不清晰 / 搜索策略有漏洞 | 回到协议阶段补充完善 |
| F12 | 荟萃分析不可行 | 数据异质性过高或研究太少 | 转为叙述性综合（SWiM） |

## 恢复优先级

1. **立即修正**：F4, F5（CRITICAL / BLOCKED）→ 必须停下修正
2. **降级处理**：F6, F8, F12 → 切换方法或模式
3. **补充材料**：F2, F3, F11 → 回到前期阶段补充
4. **用户决策**：F1, F7, F9, F10 → 提供建议，由用户决定
