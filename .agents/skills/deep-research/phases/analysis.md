# Phase 3: ANALYSIS — 跨来源综合分析

**目标**：将收集的来源综合成主题化的知识图景，识别矛盾、缺口和新的洞察。

## 3.1 主题综合

详见 `agents/synthesis_agent.md`

**关键原则：综合 ≠ 摘要堆砌。** 不是逐篇总结，而是跨来源提取主题。

### 综合方法
1. **主题提取**：从来源中提取 3-7 个交叉主题（Theme）
2. **每个主题包含**：
   - 主题名称 + 3-5 句跨来源综合描述
   - 支持来源列表（supporting_sources）
   - 矛盾来源列表（contradicting_sources，如有）
   - 强度评级：strong（5+来源）/ moderate（3-4）/ emerging（1-2）
3. **矛盾识别与解决**：
   - 明确标记来源之间的分歧
   - 比较双方证据质量
   - 给出分析判断（哪方更有力，为什么）
4. **证据收敛/发散映射**：哪些发现多来源一致？哪些存在分歧？
5. **知识缺口分析**：现有文献未能回答的问题
6. **Source-to-claim 矩阵**：为最终写作建立“来源 → 可用 claim → 文章位置”的矩阵。对 survey-of-surveys，矩阵必须逐篇列出每个 survey 贡献了哪些具体信息，不能只写“作为背景参考”。例如：某篇 survey 贡献 talking-head taxonomy，另一篇贡献 losses / metrics 表，另一篇贡献 2021-2025 方法演进。

### 理论框架整合
- 将综合结果与现有理论框架对接
- 识别理论层面的贡献点

## 3.2 Devil's Advocate Checkpoint

详见 `agents/devils_advocate_agent.md`

检查项：
- [ ] **摘樱桃检查**：是否只选了支持预设结论的来源？
- [ ] **确认偏误检测**：分析是否倾向性地解读了模糊证据？
- [ ] **逻辑链验证**：从证据到结论的推理链是否完整？
- [ ] **替代解释**：是否充分探索了其他可能的解释？
- [ ] **证据平衡**：矛盾证据是否被公平对待？

判定：**PASS** / **REVISE**（附具体反馈和修正建议）

详见 `references/logical_fallacies.md`（30+ 逻辑谬误清单）

## Gate 条件

进入 Phase 4 前必须同时满足：

1. **主题综合完成**：至少 3 个明确的综合主题
2. **Devil's Advocate PASS**：所有检查项通过
3. **缺口明确**：至少识别 2 个知识缺口
4. **todo 状态**：Phase 3 标记 `completed`，Phase 4 标记 `in_progress`

综合不够深入？补充来源或深化分析后重新检查。
