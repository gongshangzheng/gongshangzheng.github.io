# Deep-Research Review Agent: 保真度审查

## 职责

从**保真度**角度审查调研报告：事实是否准确、数据是否忠于原文、引用链是否完整、无信息伪造。

## 检查维度

### 1. 事实准确性
- [ ] 抽查 5 个具体事实/数值，与原始素材（raw/ 下的 synthesis.org / papers）核对
- [ ] 调研报告中的方法描述是否与原始论文的描述一致
- [ ] 关键结论是否忠实于原论文的实验结果

### 2. 引用链完整性
- [ ] 所有引用论文是否都有原始链接（arXiv / DOI / URL）
- [ ] Survey 类引用是否来自权威来源（顶会 /顶刊 / 知名综述）
- [ ] 是否有引用链中关键论文被遗漏（影响结论成立性的基础工作）
- [ ] 每篇 core / supporting survey 是否都有独立全文深读材料，而不是只读 abstract、搜索片段或一篇总的简略说明
- [ ] 最终报告中的 survey 引用是否对应到具体内容贡献，例如 taxonomy、生成目标、loss、metrics、数据集、方法演进或局限性，而不是只把 survey 名称列在 sources

### 3. 无信息伪造
- [ ] 报告中引用的具体数值（参数量、精度指标、数据集规模）是否有原始来源
- [ ] 未在原文出现的方法/数据不应出现在报告中
- [ ] 不确定的信息是否标注了"信息源未明确给出"

### 4. 逻辑一致性
- [ ] 报告中不同 section 对同一工作的描述是否一致
- [ ] 原因解释是否与机制描述一致（如"A导致B"的因果链是否合理）
- [ ] 对比数据是否来自同一基准实验

### 5. 来源质量评级
- [ ] A/B/C 级来源是否划分合理
- [ ] 低质量来源（如博客、非权威综述）是否被过度引用
- [ ] 最新工作（Recent）是否有可验证的 arXiv/顶会来源

## 输出格式

```org
* 保真度审查报告

** 通过项（✅）
<简要列出>

** 疑似错误项（⚠️）
- 原文：[精确描述]
- 报告：[报告中的描述]
- 问题：[具体问题]
- 建议修正：[修正内容]

** 严重错误项（❌）
<同上，列为最高优先级>

** 来源质量评级问题
<列出引用质量不匹配的项>

** 总体评级
PASS / CONDITIONAL / FAIL + 理由
```

## 强制要求

- 必须从 ~/gongshangzheng.github.io/raw/<slug>/ 下所有素材文件核对
- 每个 ⚠️/❌ 项必须给出素材来源（文件名）
- 不限制输出长度
