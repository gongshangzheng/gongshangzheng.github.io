# 标题风格：精简、准确、直接

用户于2026-10-28以《KV Cache 从哪里来：推理基础、工作过程与问题地图》及其简明章节标题为正面参照，要求后续标题沿用这种风格。本规则适用于文章标题、Hero标题及章节标题；它是默认写作偏好，不要求批量改名已有文章。

## 默认做法

- 直接点明对象与内容范围；需要时用一个具体问题或必要限定说明读者将获得什么。优先使用“KV Cache是什么”“多头注意力”“缓存的成本”这样能预告内容的表达。
- 精简是删掉无助于理解的词，不是机械压到某个字数。像“KV Cache 从哪里来：推理基础、工作过程与问题地图”这样的标题，只要各部分确有对应内容，就不必为追求短而删掉必要范围。
- 一个标题承担一个清楚的说明任务。不要堆叠多个近义修饰、缩写或用长串副标题充当目录；细节放进description、导语或正文。
- 不使用空泛或夸张的包装，如“终极指南”“彻底揭秘”“重塑未来”“一文掌握一切”。“从X到Y”等表达仅在确实描述文章范围时采用，不当成固定标题模板。
- 保留影响事实的限定：单步/累计、训练/推理、完整历史/滚动窗口等不能因简化而混淆。论文名、模型名及必要系列标识按相应规范保留，不改变正式文献题名。
- Hero标题与文章标题可长短不同，但必须表达同一对象与问题；章节标题保持一致粒度，不把解释性的整段结论塞进标题。

## 写作前后自查

读者只看标题，能否知道讲什么？每个词是否增加了必要信息？去掉修饰后是否更清楚？标题承诺是否超出正文证据？精简后是否丢失了技术边界？

用户明确指定标题时优先遵循；改名已有文章须检查站内标题引用与相关规划，不因本规则自动重命名或改slug。
